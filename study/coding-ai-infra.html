浮点 sqrt：二分与牛顿法

不调用 sqrt 或幂运算，计算有限非负浮点数 x 的平方根。先写二分，再写牛顿法；本题统一使用固定 eps=1e-10 作为停止阈值，不随数值大小缩放。

输入输出示例

  • 0 → 0；0.25 → 0.5；2 → 约 1.4142135624
  • 测试 1e-12、1e12；负数、NaN 与无穷大应拒绝。

来源 personal

需要一点提示
  • 沿用 Hot100 的 left/right、while 和 if/elif/else 写法；初始区间为 [0, max(1,x)]。这仍然是循环迭代二分。
  • 浮点版本用 / 2 取中点，偏小就 left=mid，偏大就 right=mid；比较 mid 与 x/mid 可避免平方溢出。相等可提前返回，但不能只等相等才停止。
  • 二分循环条件为 right-left>eps；区间足够窄就停止，最后返回 left 作为根的近似值。浮点端点不再变化时也要退出。
  • 牛顿法：对 y²−x 求根，更新 y ← (y+x/y)/2；abs(nxt-y)<=eps 时停止。

import math


def sqrt_binary(x, eps=1e-10):
    """有限非负浮点数；区间宽度不超过固定 eps 时停止。"""
    if not math.isfinite(x) or x < 0 or not 0 < eps < 1:
        raise ValueError("x 必须有限非负，eps 必须在 (0, 1) 内")
    if x == 0:
        return 0.0
    # x >= 1 时，sqrt(x) <= x，上界取 x。
    # 0 < x < 1 时，x < sqrt(x) < 1，上界要取 1，不能取 x。
    # 例如 x=0.25，sqrt(x)=0.5；max(1.0, x) 合并了这两种情况。
    left, right = 0.0, max(1.0, x)
    # 区间宽度不超过 eps 就停止，不用整数下标的 left <= right。
    while right - left > eps:
        mid = (left + right) / 2
        if mid == left or mid == right:  # 防止浮点精度极限导致死循环
            break
        if mid < x / mid:  # 相当于 mid * mid < x，除法可避免平方溢出
            left = mid   # 浮点数不能 mid + 1，会跳过答案
        elif mid > x / mid:
            right = mid  # 浮点数不能 mid - 1
        else:
            return mid
    return left  # 返回左端点近似值；区间宽度已满足精度或达到浮点极限


def sqrt_newton(x, eps=1e-10):
    if not math.isfinite(x) or x < 0 or not 0 < eps < 1:
        raise ValueError("x 必须有限非负，eps 必须在 (0, 1) 内")
    if x == 0:
        return 0.0
    y = max(1.0, x)
    for _ in range(2048):
        nxt = 0.5 * y + 0.5 * (x / y)
        # 相邻两次估计值的差不超过固定 eps 就停止。
        if abs(nxt - y) <= eps:
            return nxt
        y = nxt
    raise ArithmeticError("未在迭代上限内收敛")

复杂度：二分 O(log(R/δ)) 次迭代，R=max(1,x)，δ 为停止宽度；牛顿法在根附近二次收敛。额外空间 O(1)。

易错点

  • 浮点二分没有 mid±1；不要照搬整数搜索。
  • 为什么不能只用 left <= right？整数二分用 mid±1 排除中点，最终 left>right，区间变空；浮点二分用 left=mid 或 right=mid，边界不断靠近，却不一定相遇或交叉。求 sqrt(2) 时，即使区间已缩到 [1.41421,1.41422]，left<=right 仍然成立。它不足以作为浮点二分的退出条件。
  • 先理解绝对精度：while right-left>eps 表示区间还不够窄；宽度不超过 eps 就停止。忽略浮点舍入、且根始终在区间内时，返回 left 的绝对误差不超过区间宽度。
  • 两种方法都直接与固定 eps 比较：二分看 right-left，牛顿法看 abs(nxt-y)。后者是相邻迭代值的变化量，不是直接计算与真实平方根的误差。
  • 浮点舍入可能让 mid==left 或 mid==right，此时更新边界也没有进展，会导致死循环。因此还要检查端点不再变化并退出；达到浮点精度极限，不等于一定达到了任意小的 eps。
  • 平方残差 |y²−x| 与根误差 |y−√x| 不相同。
  • 固定 eps 不保证相对误差：结果很小时，即使绝对误差很小，相对误差仍可能较大；结果很大时，浮点数的表示精度可能不足以达到 eps。

面试官可能继续追问

  • 推导牛顿更新，而不是背公式。
  • 若每次迭代已无法改变浮点端点，如何终止？

MHA：从投影到输出完整手写

使用 PyTorch 基础张量操作实现 MultiHeadAttention。输入 x:[B,S,D]，H 个头，D 能被 H 整除；支持 causal 和 [B,S] 的有效 key mask。不能直接调用 nn.MultiheadAttention 或 scaled_dot_product_attention。

输入输出示例

  • B=2,S=5,D=16,H=4 → 输出 [2,5,16]
  • 固定参数、dropout=0；修改第 4 个 token，前 3 个位置的 causal 输出应不变。

来源 personal · 来源 nc-mha

需要一点提示
  • 融合投影 D→3D，reshape 为 [B,S,3,H,d]，拆出 q/k/v。
  • 换轴到 [B,H,S,d]；scores 为 [B,H,S,S]，除以 √d。
  • 对最后一维 softmax，再乘 V；换轴、contiguous、合头、输出投影。

# 基于站主已有练习实现；仅补充全 mask 行的处理。
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads, dropout=0.0):
        super().__init__()

        assert d_model % num_heads == 0

        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = self.d_model // self.num_heads

        self.dropout = nn.Dropout(dropout)

        self.qkv_proj = nn.Linear(d_model, 3*d_model)
        self.out_proj = nn.Linear(d_model, d_model)

    def forward(self, x, causal=False, attention_mask=None):
        B, S, D = x.shape
        qkv = self.qkv_proj(x)

        qkv = qkv.view(B, S, 3, self.num_heads, self.head_dim)
        q, k, v = qkv.unbind(dim=2)

        q = q.transpose(1, 2)
        k = k.transpose(1, 2)
        v = v.transpose(1, 2)

        scores = (q @ k.transpose(-1,-2)) / math.sqrt(self.head_dim)

        if causal:
            causal_mask = torch.triu(
                torch.ones(S, S, device=x.device, dtype=torch.bool),
                diagonal=1
            )
            scores = scores.masked_fill(causal_mask, float("-inf"))

        if attention_mask is not None:
            mask = attention_mask[:, None, None, :].bool()
            scores = scores.masked_fill(~mask, float("-inf"))

        # 补充：全 mask 行的注意力权重定义为零，避免 softmax(-inf) 的 NaN。
        all_masked = torch.isneginf(scores).all(dim=-1, keepdim=True)
        scores = scores.masked_fill(all_masked, 0.0)
        scores = F.softmax(scores, dim=-1)
        scores = scores.masked_fill(all_masked, 0.0)
        attn = self.dropout(scores)

        attn = attn @ v

        attn = attn.transpose(1, 2).contiguous().view(B, S, D)

        return self.out_proj(attn)

复杂度：投影 O(BSD²)，注意力 O(BS²D)，显式 scores 空间 O(BHS²)。

易错点

  • 本实现 attention_mask 的 1/True 表示有效 key；取反后才屏蔽。
  • 全 mask 行 softmax(-inf,…,-inf) 会产生 NaN；参考代码先处理该行。
  • padding mask 只屏蔽 key，不自动将 padding query 的最终输出清零；输出投影的 bias 也可能非零。
  • 本参考沿用站主已有 mha_practice.py，补充全 mask 行处理；不是对原稿的静默覆盖。

面试官可能继续追问

  • 为什么除以 √head_dim，而不是 √d_model？
  • 加入 KV cache 时怎样沿 dim=2 拼接？历史长度 P 时屏蔽条件是 key_pos > P+query_pos。
  • KV cache 元素数为 2×B×L×S×Hkv×d；再乘每元素字节数。

MQA：所有 Q 头共享一组 KV

在 MHA 基础上实现 MultiQueryAttention。Q 保持 H 个头，K/V 各只有一个头；用广播完成 attention，保持输出 [B,S,D]。

输入输出示例

  • B=2,S=5,D=16,H=4：Q=[2,4,5,4]；K/V=[2,1,5,4]。

为覆盖知识迁移新增，作为扩展练习

需要一点提示
  • Q 投影 D→D；KV 投影 D→2d。
  • KV reshape 为 [B,S,2,1,d]，转成 [B,1,S,d]。
  • 矩阵乘广播头维，无需显式复制 H 份。

# 基于站主已有练习实现；仅补充全 mask 行的处理。
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiQueryAttention(nn.Module):
    def __init__(self, d_model, num_heads, dropout=0.0):
        super().__init__()

        assert d_model % num_heads == 0

        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = self.d_model // self.num_heads

        self.q_proj = nn.Linear(d_model, d_model)
        self.kv_proj = nn.Linear(d_model, 2*self.head_dim)
        self.dropout = nn.Dropout(dropout)
        self.out_proj = nn.Linear(d_model, d_model)

    def forward(self, x, causal=False, attention_mask=None):
        B, S, D = x.shape

        q = self.q_proj(x)
        q = q.view(B, S, self.num_heads, self.head_dim)

        kv = self.kv_proj(x)
        kv = kv.view(B, S, 2, 1, self.head_dim)
        k, v = kv.unbind(dim=2)

        q = q.transpose(1, 2)
        k = k.transpose(1, 2)
        v = v.transpose(1, 2)

        scores = (q @ k.transpose(-1, -2)) / math.sqrt(self.head_dim)

        if causal:
            causal_mask = torch.triu(
                torch.ones(S, S, device=x.device, dtype=torch.bool),
                diagonal=1
            )
            scores = scores.masked_fill(causal_mask, float("-inf"))

        if attention_mask is not None:
            mask = attention_mask[:, None, None, :].bool()
            scores = scores.masked_fill(~mask, float("-inf"))

        # 补充：全 mask 行的注意力权重定义为零，避免 softmax(-inf) 的 NaN。
        all_masked = torch.isneginf(scores).all(dim=-1, keepdim=True)
        scores = scores.masked_fill(all_masked, 0.0)
        scores = F.softmax(scores, dim=-1)
        scores = scores.masked_fill(all_masked, 0.0)
        attn = self.dropout(scores)

        attn = attn @ v

        out = attn.transpose(1, 2).contiguous().view(B, S, D)

        return self.out_proj(out)

复杂度：Q/输出投影仍 O(BSD²)；注意力仍 O(BS²D)；KV cache 每层 O(BSd)。

易错点

  • 本实现 attention_mask 的 1/True 表示有效 key；取反后才屏蔽。
  • 全 mask 行 softmax(-inf,…,-inf) 会产生 NaN；参考代码先处理该行。
  • padding mask 只屏蔽 key，不自动将 padding query 的最终输出清零；输出投影的 bias 也可能非零。
  • 共享的是 KV 头，不是把所有 Q 头求平均。

  • KV cache 大小相较同配置 MHA 缩小几倍？
  • 广播省了 KV 存储，是否也让 scores 只剩一个头？为什么不是？

GQA：按组共享 KV

实现 MultiGroupAttention(d_model,num_heads,group)。这里 group 是 KV 头数 G；要求 H%G==0，每个 KV 头供连续的 H/G 个 Q 头使用。

输入输出示例

  • H=8,G=2：KV 头序列映射为 [0,0,0,0,1,1,1,1]。
  • G=H 对应 MHA 头结构；G=1 对应 MQA 头结构（比较输出需对齐权重）。

为覆盖知识迁移新增，作为扩展练习

需要一点提示
  • KV 投影 D→2Gd；先得到 [B,S,G,d]。
  • repeat_interleave(H//G,dim=2)，然后换轴。
  • 后续注意力计算沿用 MHA。

# 基于站主已有练习实现；仅补充全 mask 行的处理。
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiGroupAttention(nn.Module):
    def __init__(self, d_model, num_heads, group, dropout=0.0):
        super().__init__()

        assert d_model % num_heads == 0
        assert 1 <= group <= num_heads
        assert num_heads % group == 0

        self.d_model = d_model
        self.num_heads = num_heads
        self.group = group
        self.head_dim = d_model // num_heads

        self.dropout = nn.Dropout(dropout)
        self.q_proj = nn.Linear(d_model, d_model)
        self.kv_proj = nn.Linear(d_model, 2 * group * self.head_dim)

        self.out_proj = nn.Linear(d_model, d_model)

    def forward(self, x, causal=False, attention_mask=None):
        B, S, D = x.shape

        q = self.q_proj(x)
        kv = self.kv_proj(x)

        q = q.view(B, S, self.num_heads, self.head_dim)

        kv = kv.view(B, S, 2, self.group, self.head_dim)
        k, v = kv.unbind(dim=2)

        kv_num_heads = self.num_heads // self.group

        k = k.repeat_interleave(kv_num_heads, dim=2)
        v = v.repeat_interleave(kv_num_heads, dim=2)

        q = q.transpose(1, 2)
        k = k.transpose(1, 2)
        v = v.transpose(1, 2)

        scores = (q @ k.transpose(-1, -2)) / math.sqrt(self.head_dim)

        if causal:
            causal_mask = torch.triu(
                torch.ones(S, S, device=x.device, dtype=torch.bool),
                diagonal=1
            )
            scores = scores.masked_fill(causal_mask, float("-inf"))
        if attention_mask is not None:
            mask = attention_mask[:, None, None, :].bool()
            scores = scores.masked_fill(~mask, float("-inf"))

        # 补充：全 mask 行的注意力权重定义为零，避免 softmax(-inf) 的 NaN。
        all_masked = torch.isneginf(scores).all(dim=-1, keepdim=True)
        scores = scores.masked_fill(all_masked, 0.0)
        scores = F.softmax(scores, dim=-1)
        scores = scores.masked_fill(all_masked, 0.0)
        attn = self.dropout(scores)

        attn = attn @ v
        out = attn.transpose(1, 2).contiguous().view(B, S, D)

        return self.out_proj(out)

复杂度：注意力 O(BS²D)；未展开 KV cache 每层 O(BSGd)。示范 repeat_interleave 临时展开到 H 头。

易错点

  • 本实现 attention_mask 的 1/True 表示有效 key；取反后才屏蔽。
  • 全 mask 行 softmax(-inf,…,-inf) 会产生 NaN；参考代码先处理该行。
  • padding mask 只屏蔽 key，不自动将 padding query 的最终输出清零；输出投影的 bias 也可能非零。
  • repeat 与 repeat_interleave 不等价，前者可能得到 [0,1,0,1,…] 的错误头映射。
  • 演示展开有额外内存开销；KV cache 应保存展开前的 G 个头。

面试官可能继续追问

  • 不实际展开 KV，如何用 reshape/einsum 按组计算？
  • 为什么 GQA 不能直接通过少存任意 MHA 的几个 KV 头实现无损转换？

LRU Cache：哈希表与双向链表

实现 LRUCache(capacity)、get(key)、put(key,value)，平均 O(1)。不存在返回 -1；访问与更新都刷新最近使用顺序。本练习额外约定容量为 0 时不保存任何项。

输入输出示例

  • 容量 2：put(1,1),put(2,2),get(1),put(3,3)，随后 get(2)=-1。
  • 更新已有 key 后再插入新 key，应淘汰其他最久未用项。

来源 xhs-lru

需要一点提示
  • 沿用已有笔记：head 后最旧，tail 前最新。
  • 拆成 _remove 与 _append，复用指针操作。
  • 节点必须保存 key，淘汰时才能同步删除哈希表。
写下你的代码与思路
展开参考答案与易错点
下载 .pyHot100 原笔记：LRU →
class ListNode:
    def __init__(self, key=0, val=0):
        self.key, self.val = key, val
        self.prev = self.next = None


class LRUCache:
    """沿用原笔记约定：头部最旧，尾部最新。"""
    def __init__(self, capacity):
        if capacity < 0:
            raise ValueError("capacity 必须非负")
        self.capacity = capacity
        self.nodes = {}
        self.head, self.tail = ListNode(), ListNode()
        self.head.next, self.tail.prev = self.tail, self.head

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _append(self, node):
        node.prev, node.next = self.tail.prev, self.tail
        self.tail.prev.next = node
        self.tail.prev = node

    def get(self, key):
        node = self.nodes.get(key)
        if node is None:
            return -1
        self._remove(node)
        self._append(node)
        return node.val

    def put(self, key, value):
        if self.capacity == 0:
            return
        node = self.nodes.get(key)
        if node is not None:
            node.val = value
            self._remove(node)
        else:
            node = ListNode(key, value)
            self.nodes[key] = node
        self._append(node)
        if len(self.nodes) > self.capacity:
            old = self.head.next
            self._remove(old)
            del self.nodes[old.key]

复杂度：get/put 平均 O(1)，空间 O(capacity)。

易错点

  • 先改 node 的 prev/next，再修改旧尾节点和 tail 的指针。
  • 淘汰链表节点后不能忘记删字典。

稳定 Softmax：数值与 mask

先输入一维 logits，手写稳定 Softmax，不直接调用库的 softmax。允许有限值和 -inf；空列表返回空列表，全 -inf 约定返回全零，NaN/+inf 拒绝。再对照参考答案中的 PyTorch 张量版，理解 Attention 如何沿 key 维度分别归一化。

输入输出示例

  • [1000,1001] → 约 [0.268941,0.731059]
  • [0,-inf] → [1,0]；[-inf,-inf] → [0,0]。

来源 xhs-softmax

需要一点提示
  • 先减去最大值，再 exp、求和、归一化。
  • 解释减常数不改变数学上的结果。
  • 全 mask 行需要独立约定；全零不是一个归一化概率分布。
  • MHA、MQA、GQA 的 scores 通常为 [B,H,Q,K]，H 是 Q 头数；每个 query 对所有 key 的分数构成一行。dim=-1 沿 K 计算，不能把整个张量一起归一化。
  • keepdim=True 使最大值和指数和保留 [B,H,Q,1] 的形状，通过广播作用到每行的 K 个分数；.values 取 max 返回的最大值，不取其索引。

展开参考答案与易错点

import math


def stable_softmax(logits):
    """logits 是一组原始分数；接受有限数或 -inf，全 -inf 时返回全零。"""
    if not logits:
        return []
    if any(math.isnan(score) or score == math.inf for score in logits):
        raise ValueError("不接受 NaN 或 +inf")

    max_score = max(logits)
    # 全部被 mask 时，按本题约定返回全零，避免 -inf - (-inf) 产生 NaN。
    if max_score == -math.inf:
        return [0.0] * len(logits)

    # 每个分数减去相同的最大值，Softmax 结果不变，并能避免指数溢出。
    exp_scores = [math.exp(score - max_score) for score in logits]
    sum_exp_scores = sum(exp_scores)

    # 每项除以指数值之和，得到总和为 1 的概率。
    probabilities = [exp_score / sum_exp_scores for exp_score in exp_scores]
    return probabilities


def stable_softmax_attention(scores):
    """Attention 张量版：scores 为浮点张量 [B, H, Q, K]。

    B 是 batch 大小，H 是 Q 头数，Q/K 是 query/key 序列长度。
    输入允许有限分数和 -inf；此核心版本要求每行至少有一个有限分数。
    """
    import torch

    # 固定 batch、head、query，沿最后一维 K 独立做一次 Softmax。
    # keepdim=True 保留长度为 1 的维度，便于广播回 [B, H, Q, K]。
    max_scores = scores.max(dim=-1, keepdim=True).values  # [B, H, Q, 1]
    exp_scores = torch.exp(scores - max_scores)          # [B, H, Q, K]
    sum_exp_scores = exp_scores.sum(dim=-1, keepdim=True) # [B, H, Q, 1]
    probabilities = exp_scores / sum_exp_scores          # [B, H, Q, K]
    return probabilities

复杂度：O(n) 时间；此参考实现使用 O(n) 中间空间。

易错点

  • 不减最大值可能 exp 溢出。
  • 不要通过把 -inf 全替换为一个有限负数来掩盖全 mask 语义。
  • 补充的张量核心版本假设 K>0、每行至少有一个有限分数，且没有 NaN/+inf；全 -inf 行会产生 NaN，不能直接套用一维函数的全零约定。若要支持全 mask 行，需要另行处理。
  • MQA/GQA 共享 K/V 头，但每个 Q 头仍有自己的注意力权重；Softmax 仍沿最后一维 key_len 计算，每行的概率和约为 1。

Online Softmax：在线更新统计量

逐个读入 logits，在线维护最大值 max_score 与指数和 sum_exp_scores；第二遍生成概率。变量名与稳定 Softmax 保持一致。返回完整概率需要再次访问输入；本题不声称一遍、常数总空间就能输出完整 Softmax。

输入输出示例

  • [1000,1001,-1000] 与普通稳定 Softmax 一致。
  • 分块前后的归一化统计量合并应得到相同结果。

为覆盖知识迁移新增，作为扩展练习

需要一点提示
  • 读入当前分数 score，更新最大值：new_max_score=max(max_score,score)。
  • 先更新指数和：sum_exp_scores=sum_exp_scores*exp(max_score-new_max_score)+exp(score-new_max_score)，然后再令 max_score=new_max_score。
  • 两个分块合并时，用 m 表示最大值、l 表示指数和：m=max(m1,m2)，l=l1*exp(m1-m)+l2*exp(m2-m)。
写下你的代码与思路
展开参考答案与易错点

import math


def online_softmax(logits):
    """logits 是一组原始分数；两遍计算，全 -inf 时返回全零。"""
    if not logits:
        return []

    # 第一遍：逐个读入分数，维护当前最大值和对应的指数和。
    # 关键：sum_exp_scores 是已处理分数减去当前 max_score 后的指数和，
    # 即 sum(exp(已处理分数 - max_score))，不是原始的 sum(exp(已处理分数))。
    max_score = -math.inf
    sum_exp_scores = 0.0
    for score in logits:
        if math.isnan(score) or score == math.inf:
            raise ValueError("不接受 NaN 或 +inf")
        # 被 mask 的分数不贡献概率；跳过也能避免 -inf - (-inf)。
        if score == -math.inf:
            continue

        new_max_score = max(max_score, score)
        # exp(旧分数 - 新最大值) = exp(旧分数 - 旧最大值) * exp(旧最大值 - 新最大值)。
        # 最大值变大，旧项应该缩小，所以乘 exp(max_score - new_max_score)。
        # 新分数也要减去 new_max_score，不能直接加 exp(score)。
        sum_exp_scores = (
            sum_exp_scores * math.exp(max_score - new_max_score)
            + math.exp(score - new_max_score)
        )
        max_score = new_max_score

    # 全部被 mask 时，按本题约定返回全零。
    if max_score == -math.inf:
        return [0.0] * len(logits)

    # 第二遍：用最终的最大值和指数和，计算每个分数对应的概率。
    probabilities = [math.exp(score - max_score) / sum_exp_scores for score in logits]
    return probabilities

复杂度：两遍 O(n) 时间；统计量 O(1)，返回列表 O(n)，需要可重读输入。

易错点

  • 关键定义：sum_exp_scores 保存的是已处理分数减去当前最大值后的指数和，即 sum(exp(已处理分数-max_score))，不是原始的 sum(exp(已处理分数))。
  • 不能只累加 exp(score-new_max_score)：旧指数和也要乘 exp(max_score-new_max_score)，统一到新最大值的尺度；完成换算前不要覆盖旧 max_score。
  • 缩放因子的正负方向别写反：最大值变大，旧指数项应该变小，所以是 exp(旧最大值-新最大值)，而不是反过来；新项同样要减去新最大值。例：先读 2、3，指数和为 exp(-1)+1；再读 5，更新为 (exp(-1)+1)*exp(3-5)+exp(5-5)。
  • FlashAttention 还要维护与 V 相关的加权累加器，不只是这两个统计量。

def unique_paths(m, n):
    if m <= 0 or n <= 0:
        return 0
    dp = [1] * n
    for _ in range(1, m):
        for j in range(1, n):
            dp[j] += dp[j - 1]
    return dp[-1]


def paths_with_obstacles(grid):
    if not grid or not grid[0]:
        return 0
    dp = [0] * len(grid[0])
    dp[0] = 1
    for row in grid:
        for j, blocked in enumerate(row):
            if blocked:
                dp[j] = 0
            elif j > 0:
                dp[j] += dp[j - 1]
    return dp[-1]

复杂度：O(mn) 时间、O(n) 额外空间。

def min_path_sum(grid):
    if not grid or not grid[0]:
        return 0
    n = len(grid[0])
    dp = [float("inf")] * n
    dp[0] = 0
    for row in grid:
        for j, value in enumerate(row):
            left = dp[j - 1] if j > 0 else float("inf")
            dp[j] = min(dp[j], left) + value
    return dp[-1]

复杂度：O(mn) 时间、O(n) 额外空间。

无重复字符的最长子串

给定字符串 s，求不含重复字符的最长连续子串长度。

需要一点提示

  • 每轮用 j-i 更新 res，再记录 hash_dic[s[j]]=j。参考代码只去掉 Solution 类和 self，保留原函数名与变量。

def lengthOfLongestSubstring(s: str) -> int:
    i = -1
    res = 0
    hash_dic = {}
    for j in range(len(s)):
        if s[j] in hash_dic: # 重复出现了
            i = max(i, hash_dic[s[j]])
        res = max(res, (j - i)) # 每次都比较，因为可能出现从头到尾都没有重复的情况
        hash_dic[s[j]] = j
    return res

复杂度：O(n) 时间，O(字符集大小) 空间。

易错点

  • i 是不包含在窗口内的左边界，因此窗口长度为 j-i，不是 j-i+1。
  • 不能直接令 i=hash_dic[s[j]]，旧位置可能已在窗口之外；要取 max，防止左边界后退。

最长回文子串：动态规划

返回字符串 s 的一个最长回文子串。并列时返回任意一个即可，同时考虑奇数与偶数长度。

输入输出示例

  • babad → bab 或 aba；cbbd → bb
  • 空字符串 → 空字符串；aaaa → aaaa。

来源 nc-palindrome

需要一点提示
  • 沿用 Hot100 的二维 DP：dp[i][j] 表示闭区间 s[i:j+1] 是否为回文；单字符 dp[i][i]=True。
  • 按 length 从 2 到 n 枚举长度，再枚举起点 i，终点 j=i+length-1；先有短区间结果，才能判断长区间。
  • 当 s[i]==s[j]，且 length==2 或 dp[i+1][j-1]==True 时，标记 dp[i][j]=True，并更新 max_length、start；最后返回 s[start:start+max_length]。参考代码只去掉 Solution 类和 self。
写下你的代码与思路
展开参考答案与易错点
下载 .pyHot100 原笔记：最长回文子串 →
def longestPalindrome(s: str) -> str:
    n = len(s)
    max_length = 1
    start = 0
    dp = [[False] * n for _ in range(n)]

    for i in range(n):
        dp[i][i] = True
    for length in range(2, n+1):
        for i in range(n-length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                if length == 2 or dp[i+1][j-1] == True:
                    dp[i][j] = True
                    if length > max_length:
                        max_length = length
                        start = i

    return s[start: start+max_length]

复杂度：O(n²) 时间，二维 dp 表占 O(n²) 额外空间。

易错点

  • 二维表用 [[False]*n for _ in range(n)]，不能用 [[False]*n]*n，否则各行共享同一个列表。
  • 长度为 2 时只需两端字符相等，不能依赖内部区间的状态；原代码用 or 的短路判断处理。
  • 只有 length>max_length 时才更新答案；空串时循环不执行，最终切片仍返回空串。
