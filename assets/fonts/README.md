# Homepage title font

`ma-shan-zheng-title.ttf` is a four-character subset (支线客栈) of Ma Shan Zheng, downloaded through the Google Fonts CSS API on 2026-10-19. It is self-hosted; the page makes no font request to Google.

Source: https://github.com/googlefonts/mashanzheng
License: SIL Open Font License 1.1, included in `ma-shan-zheng-OFL.txt`.

Only the homepage hero heading uses this subset. If its wording changes, regenerate the subset for the new characters.
