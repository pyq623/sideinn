- `model.mjs`：确定性数值模型；6 层、二维、单头、人工权重、窗口 3、Top-2、K/V 绑定、残差系数 0.3。encoder 第 2 层从第一层输出投影 A；decoder 第 4 层从第三层输出投影 C。跨层共享保持同一缓存对象，索引与主注意力查询分离。

任何新解释都要区分真实机制与人工模型。不可将权重、token 切分、误差大小、层数、候选池大小或工作量比写成 DeepSeek 的实测结果。这里没有训练语言模型、LM head、采样器、量化、MoE、RoPE 或 mHC。索引器是教学点积实现，不等同于论文完整 indexer。官方机制来源和省略项在页面可见。
