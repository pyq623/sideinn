刷题时随用随查。示例以常见 Python 3 写法为主；nums 表示列表，n 表示元素数量。

1. random：随机取一个、多个与打乱

先写 import random。下面三种抽样默认对各位置等概率选择：

方法返回值重复与限制
random.choice(nums)一个元素取一次；nums 不能为空
random.sample(nums, k=3)含 3 个元素的新列表不放回，同一位置不重复；0 ≤ k ≤ len(nums)
random.choices(nums, k=3)含 3 个元素的新列表有放回，同一位置可重复；k 可超过长度，k > 0 时 nums 不能为空
import random
nums = [1, 2, 3, 4, 5]
one = random.choice(nums)         # 例如 3
many = random.sample(nums, k=3)    # 例如 [4, 1, 5]
repeat = random.choices(nums, k=3) # 例如 [2, 2, 5]
random.shuffle(nums)              # 原地打乱，返回 None
r = random.randint(1, 6)          # 整数 1～6，两端都包含
r = random.randrange(1, 6)        # 整数 1～5，不包含 6

sample 不保证值唯一：[1, 1, 2] 中的两个 1 位于不同位置，可以都被抽中。快排每轮只需一个 pivot，所以用 choice。

2. sort 与 sorted：是否修改原列表

写法结果修改原对象？
nums.sort()原地升序排序，返回 None是；仅列表方法
sorted(nums)返回排好的新列表否；也接受元组、字典等可迭代对象
sorted(nums, reverse=True)降序的新列表否
nums.reverse() / nums[::-1]前者原地反转并返回 None；后者返回反转副本前者是，后者否；反转不等于排序
nums = [3, 1, 2]
ordered = sorted(nums)      # ordered=[1, 2, 3]，nums 仍为 [3, 1, 2]
nums.sort(reverse=True)     # nums=[3, 2, 1]；不要写 nums = nums.sort()
pairs = [(2, 3), (1, 5), (2, 1)]
ordered = sorted(pairs, key=lambda p: (p[0], -p[1]))
# [(1, 5), (2, 3), (2, 1)]：第一项升序，相同则第二项降序
words = sorted(["pear", "a", "to"], key=len)  # 按字符串长度排序

key 指定比较依据；sort 也支持 key 和 reverse。两者都是稳定排序：key 相同的元素保留原先相对顺序。列表排序时间为 O(n log n)（最坏）。

3. math 与基本数值运算

先写 import math；下面的 abs、pow、round 是内置函数，无需导入。

用途写法与结果
平方根 / 整数平方根math.sqrt(10) ≈ 3.162；math.isqrt(10) → 3（非负整数平方根向下取整）
向下 / 向上取整math.floor(-1.2) → -2；math.ceil(-1.2) → -1
绝对值 / 幂abs(-3) → 3；2 ** 3 → 8；pow(2, 10, 1000) → 24（幂取模）
对数math.log(1) → 0.0（自然对数）；math.log2(8) → 3.0；math.log10(100) → 2.0
最大公约数 / 最小公倍数math.gcd(12, 18) → 6；math.lcm(12, 18) → 36（Python 3.9+）
阶乘 / 组合数math.factorial(5) → 120；math.comb(5, 2) → 10
常量 / 浮点比较math.pi；math.inf、-math.inf；math.isclose(0.1 + 0.2, 0.3) → True

7 // 3 == 2，7 % 3 == 1，divmod(7, 3) == (2, 1)。// 向下取整：-7 // 3 == -3；int(-1.8) == -1 则是向零截断。round 不应简单当作“四舍五入”：round(2.5) == 2、round(3.5) == 4（正好居中时取偶数）。

4. 列表与数组：索引、增删与复制

Hot100 中的“数组”通常直接用 Python list 表示，不必额外引入 NumPy。索引从 0 开始，a[-1] 是最后一个元素；切片 a[start:end:step] 左闭右开。

a = [10, 20, 30]
a.append(40)          # 尾部加一个元素：[10, 20, 30, 40]
a.extend([50, 60])    # 加入多个元素；append([50, 60]) 则加入一个子列表
last = a.pop()        # 删除并返回末尾的 60
item = a.pop(1)       # 删除并返回下标 1 的 20
a.remove(30)          # 删除第一个值为 30 的元素；不存在则报错
a.insert(0, 5)       # 在下标 0 前插入 5
part = a[1:3]        # 取下标 1、2，不修改 a
copy = a.copy()       # 浅复制；a[:] 也可以
squares = [x*x for x in range(5) if x % 2 == 0]  # [0, 4, 16]

下标读写 O(1)，尾部 append/pop 摊还 O(1)；头部或中间插入、删除通常 O(n)，x in a 也通常 O(n)。b = a 只是指向同一列表；浅复制仍共享内部可变对象。

rows, cols = 2, 3
matrix = [[0] * cols for _ in range(rows)]  # 每行是独立列表
matrix[0][0] = 1
# [[1, 0, 0], [0, 0, 0]]
# 不要用 [[0] * cols] * rows：多行会引用同一列表

若确实需要标准库的同类型数值数组，可用 from array import array，再写 a = array('i', [1, 2, 3])；普通刷题使用 list 即可。

5. 字典、计数与集合

d = {"a": 2}
d["b"] = 3                 # 新增或修改
value = d.get("c", 0)       # 不存在时返回 0，不插入 c
exists = "a" in d           # 检查的是键
pairs = list(d.items())     # [("a", 2), ("b", 3)]
keys, values = list(d.keys()), list(d.values())
removed = d.pop("b", 0)     # 删除并返回；不存在则返回默认值 0
for key, value in d.items():
    print(key, value)

from collections import Counter, defaultdict
freq = Counter([1, 1, 2])   # {1: 2, 2: 1}；freq[9] 返回 0
most = freq.most_common(1)  # [(1, 2)]，返回 (元素, 次数)
groups = defaultdict(list)
groups["a"].append(1)      # 缺失的键自动创建空列表

字典键必须可哈希：数字、字符串、元素都可哈希的元组可以；列表不可以。键的查找、插入、删除平均 O(1)。sorted(d) 得到排好的键列表；按值排序可写 sorted(d.items(), key=lambda p: p[1])。

seen = set()                # 空集合；{} 是空字典
seen.add(3)
seen.discard(4)              # 不存在也不报错；remove(4) 会报错
exists = 3 in seen
unique = set([1, 1, 2])      # {1, 2}，不保证遍历顺序
common = {1, 2} & {2, 3}     # {2}：交集；| 为并集，- 为差集

6. 栈与队列：list / deque

用途写法含义
栈stack = []；stack.append(x)；stack.pop()后进先出；stack[-1] 只看栈顶
队列q = deque()；q.append(x)；q.popleft()先进先出，常用于 BFS；两端操作约 O(1)
双端队列q.appendleft(x)；q.pop()也能从左入、从右出
from collections import deque
q = deque([1, 2])
q.append(3)
first = q.popleft()  # 1；剩余 deque([2, 3])
while q:            # 非空才取，避免空队列报错
    item = q.popleft()

不要用列表的 pop(0) 频繁出队，每次都需移动后续元素。deque 适合两端操作，不适合频繁访问中间下标。

7. heapq：最小堆与 Top K

heapq 直接在列表上维护堆。默认小顶堆，heap[0] 最小，整个列表不一定有序。

import heapq
heap = [3, 1, 4]
heapq.heapify(heap)            # 原地建堆，O(n)，返回 None
heapq.heappush(heap, 2)        # 入堆，O(log n)
smallest = heap[0]            # 看最小值，O(1)
smallest = heapq.heappop(heap) # 弹出最小值 1，O(log n)
nums = [3, 1, 4, 2]
top = heapq.nlargest(2, nums)  # [4, 3]
bottom = heapq.nsmallest(2, nums)  # [1, 2]

# 常见兼容写法：负数小顶堆模拟最大堆（针对数值）
max_heap = [-x for x in nums]
heapq.heapify(max_heap)
largest = -heapq.heappop(max_heap)  # 4

Python 3.14+ 也提供 heapify_max、heappush_max、heappop_max。练习平台版本不确定时，数值最大堆可用上面的负数写法。空堆不能取 heap[0] 或 heappop；存 (优先级, 元素) 时，优先级相同会继续比较后面的元素。

关联题：215 · 第 K 大、347 · 前 K 个高频元素。

写法用途或结果
