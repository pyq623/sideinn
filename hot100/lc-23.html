第 34 题 合并 K 个升序链表

LeetCode 23 Merge k Sorted Lists

难度 困难 标签 链表 分治 堆（优先队列） 原题链接

题面

给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

示例 1：

输入： lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释： 链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到。
1->1->2->3->4->4->5->6

示例 2：

输入： lists = []
输出：[]

示例 3：

输入： lists = [[]]
输出：[]

提示：

  • k == lists.length
  • 0 <= k <= 10^4
  • 0 <= lists[i].length <= 500
  • -10^4 <= lists[i][j] <= 10^4
  • lists[i] 按 升序 排列
  • lists[i].length 的总和不超过 10^4

思路

  • 核心思想：用最小堆维护"每个链表当前的最小节点"，每次从堆顶弹出全局最小的节点接到结果链表，然后把该节点的 next 入堆
  • 流程：
  1. 把所有链表的头节点放入堆（跳过空链表）
  2. while 堆不为空：弹出最小节点，接到结果链表末尾，如果该节点有 next 就入堆
  3. 返回哨兵节点的 next
  • 为什么时间复杂度是 O(L log m)（L = 总节点数，m = 链表个数）：
  • 堆里始终最多 m 个节点（每个链表最多贡献一个）
  • 每个节点被 pop 一次、push 一次，每次操作 O(log m)
  • 总共 L 个节点 × O(log m) = O(L log m)

Python 新语法 函数讲解

  1. `ListNode.__lt__ = lambda a, b: a.val < b.val`
  • 给 ListNode 类动态添加小于比较方法
  • __lt__ 是 Python 魔术方法，a < b 实际调用 a.__lt__(b)
  • 堆内部需要用 < 比较元素，ListNode 默认没定义比较，不加这行会报 TypeError: '<' not supported between instances of 'ListNode' and 'ListNode'
  1. `heapify(h_list)`（需要 from heapq import heapify, heappush, heappop）
  • 原地把列表变成最小堆，时间 O(m)
  • 堆化后 h_list[0] 是最小元素
  • 内部比较使用 __lt__，所以堆顶是 .val 最小的节点
  1. `heappop(h_list)`
  • 弹出并返回堆顶（最小）元素，自动维护堆性质，O(log m)
  • 是模块级函数，不是列表的方法：heappop(h) ✓，h.heappop() ✗
  1. `heappush(h_list, node)`
  • 往堆里插入元素并自动上浮调整，维护堆性质，O(log m)
  1. `[head for head in lists if head]`
  • 列表推导式 + 过滤：只保留非空（非 None）的头节点
  • if head 过滤掉 None 和空链表，避免把 None 放进堆导致比较报错

易错点

  1. 必须用 `heappush` 而不是 `append`：append 只在末尾加元素，不维护堆的顺序，下次 heappop 拿到的就不是最小值了
  2. 必须定义 `__lt__`：没有比较方法，heapify/heappush/heappop 全都会报错
  3. 列表推导里 `if head` 不能省：lists 可能包含 None 或空链表（如 [[]] 对应 [None]），不过滤就会把 None 放进堆

代码实现

import heapq
ListNode.__lt__ = lambda a, b: a.val < b.val

class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        cur = dum = ListNode(0)
        h_list = [head for head in lists if head]
        heapify(h_list)
        while h_list:
            s_node = heappop(h_list)
            if s_node.next:
                heappush(h_list, s_node.next)
            cur.next = s_node
            cur = cur.next
        return dum.next
  • 复杂度：时间 O(L log m)（L 为总节点数，m 为链表个数），空间 O(m)（堆的大小）

写法二 元组入堆 不修改 ListNode

思路

  • 和写法一逻辑完全相同，唯一区别：堆里放的不是 ListNode 对象，而是元组 `(val, i, node)`
  • 这样就不需要给 ListNode 定义 __lt__，因为 Python 比较元组是逐元素比较：
  1. 先比 val（int，一定能比）
  2. 如果 val 相同，比 i（每个链表的唯一编号，一定不相等）
  3. 永远不会比到第三个元素 node——所以 ListNode 不需要支持比较
  • i 的作用是 tiebreaker（打破平局）：同一条链表的节点始终用同一个 i，不同链表的 i 不同，保证第二层一定能分出大小

代码实现

class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        cur = dum = ListNode(0)
        h = [(head.val, i, head) for i, head in enumerate(lists) if head]
        heapify(h)
        while h:
            _, i, node = heappop(h)
            if node.next:
                heappush(h, (node.next.val, i, node.next))
            cur.next = node
            cur = cur.next
        return dum.next
  • 复杂度：同写法一
