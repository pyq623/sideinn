第 76 题 数据流的中位数

LeetCode 295 Find Median from Data Stream

难度 困难 标签 堆 设计 双指针 数据流 排序 堆（优先队列） 原题链接

题面

中位数 是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

  • 例如 arr = [2,3,4] 的中位数是 3 。
  • 例如 arr = [2,3] 的中位数是 (2 + 3) / 2 = 2.5 。

实现 MedianFinder 类:

  • MedianFinder() 初始化 MedianFinder 对象。
  • void addNum(int num) 将数据流中的整数 num 添加到数据结构中。
  • double findMedian() 返回到目前为止所有元素的中位数。与实际答案相差 10-5 以内的答案将被接受。

示例 1：

输入
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]
输出
[null, null, null, 1.5, null, 2.0]

解释
MedianFinder medianFinder = new MedianFinder();
medianFinder.addNum(1);    // arr = [1]
medianFinder.addNum(2);    // arr = [1, 2]
medianFinder.findMedian(); // 返回 1.5 ((1 + 2) / 2)
medianFinder.addNum(3);    // arr[1, 2, 3]
medianFinder.findMedian(); // return 2.0

提示:

  • -105 <= num <= 105
  • 在调用 findMedian 之前，数据结构中至少有一个元素
  最多 `5  104` 次调用 `addNum` 和 `findMedian`

思路

用两个堆把数据流切成两半：

排序后：[1, 2, 3, | 5, 7, 8]
        ← big_heap →  ← small_heap →
        大顶堆(存负号)    小顶堆
        堆顶 = 3         堆顶 = 5
  • big_heap（大顶堆）：存较小的一半，堆顶是左半边的最大值
  • small_heap（小顶堆）：存较大的一半，堆顶是右半边的最小值

Python 没有大顶堆，所以 big_heap 存负号，取的时候再取负。

addNum 的核心 绕一圈

不需要判断 num 该去哪个堆，让堆自动帮你分配：

  • 想往 A 加 → 先 push 进 B → B 把最该去 A 的弹出来 → push 进 A

这样堆自动完成了大小排序，保证 big 所有元素 ≤ small 所有元素。

我们选的规则是"相等时往 small 加"，所以 small 的个数始终 ≥ big：

绕一圈的过程

len(small) == len(big)

往 small 加

num → big → 弹出 big 最大 → 放进 small

len(small) > len(big)

往 big 加

num → small → 弹出 small 最小 → 放进 big

走一遍例子

addNum(5): small==big==0, 往 small 加
  → 5 放进 big → big 弹出 5 → 放进 small
  big=[]  small=[5]

addNum(2): small 多了, 往 big 加
  → 2 放进 small → small 弹出 2 → 放进 big
  big=[2]  small=[5]

addNum(1): small==big, 往 small 加
  → 1 放进 big → big 弹出 2(最大的) → 放进 small
  big=[1]  small=[2,5]

addNum(7): small 多了, 往 big 加
  → 7 放进 small → small 弹出 2(最小的) → 放进 big
  big=[1,2]  small=[5,7]

排序后 [1, 2 | 5, 7]，完美对半分。

findMedian

  • 偶数个：两个堆顶的平均值 = (small[0] + (-big[0])) / 2
  • 奇数个：small 多一个，中位数 = small[0]

heapq 小知识

  • heap[0]：只看堆顶，不弹出（和栈的 stack[-1] 一样，只看不动）
  • heappop(heap)：弹出堆顶（和 stack.pop() 一样，看了还弹走）
  • heappush(heap, val)：往堆里加一个元素

代码实现

class MedianFinder:

    def __init__(self):
        self.small = []
        self.big = []

    def addNum(self, num: int) -> None:
        if len(self.small) == len(self.big):
            # 往 small 里加：num → big → 弹出 big 最大 → 放进 small
            heappush(self.big, -num)
            top = heappop(self.big)
            heappush(self.small, -top)
        else:
            # 往 big 里加：num → small → 弹出 small 最小 → 放进 big
            heappush(self.small, num)
            top = heappop(self.small)
            heappush(self.big, -top)

    def findMedian(self) -> float:
        if len(self.small) == len(self.big):
            median = (self.small[0] + -self.big[0]) / 2
        else:
            median = self.small[0]
        return median
  • 易错点：
  1. big_heap 存负号，取的时候取负：Python 只有小顶堆，heappush(big, -num) 存入，-heappop(big) 取出。忘记取负会导致结果全是负数
  2. "绕一圈"是三行代码，不是一行：push 进一个堆 → pop 出来 → push 进另一个堆，不能跳过中间步骤直接放
  3. findMedian 取 big 堆顶时要取负：-self.big[0] 才是真实值，写成 self.big[0] 就是负数了
  4. "相等时往哪加"和"findMedian 从哪取"要一致：我们选相等时往 small 加，所以奇数个时中位数是 small[0]。如果选相等时往 big 加，奇数个就得取 -big[0]
  • 复杂度：addNum O(log n)（三次堆操作），findMedian O(1)（取堆顶），空间 O(n)
