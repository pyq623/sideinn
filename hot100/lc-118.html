第 82 题 杨辉三角

LeetCode 118 Pascal's Triangle

难度 简单 标签 动态规划 数组 原题链接

题面

给定一个非负整数 numRows，生成「杨辉三角」的前 numRows 行。

在「杨辉三角」 中，每个数是它左上方和右上方的数的和。

示例 1:

输入: numRows = 5
输出: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]

示例 2:

输入: numRows = 1
输出: [[1]]

提示:

  • 1 <= numRows <= 30

思路

每一行的首尾都是 1，中间的元素 = 上一行左上 + 上一行右上：

row[j] = results[i-1][j-1] + results[i-1][j]
i=0: [1]
i=1: [1, 1]
i=2: [1, 1+1, 1] = [1, 2, 1]
i=3: [1, 1+2, 2+1, 1] = [1, 3, 3, 1]
i=4: [1, 1+3, 3+3, 3+1, 1] = [1, 4, 6, 4, 1]

为什么要用二维结构 读旧行 写新行

如果用一维 dp 从左到右更新，dp[j-1] 会被覆盖成新值，导致后面的计算拿到的是错误的值：

上一行 dp = [1, 2, 1]

j=1: dp[1] = dp[0] + dp[1] = 1 + 2 = 3 ✓
j=2: dp[2] = dp[1] + dp[2] = 3 + 1 = 4 ✗
                               ↑ 已被覆盖成 3，应该是 2

用二维结构，上一行在 results[i-1]，当前行在 res，互不干扰：

results[i-1] = [1, 2, 1]  ← 不会被修改

res[1] = results[i-1][0] + results[i-1][1] = 1 + 2 = 3 ✓
res[2] = results[i-1][1] + results[i-1][2] = 2 + 1 = 3 ✓

range 1 i 为什么不报错

range(1, 0) 和 range(1, 1) 都是空范围，循环体不执行。第 0 行 [1] 和第 1 行 [1,1] 没有中间元素需要计算，全 1 直接就是对的。

代码实现

class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        results = []
        for i in range(numRows):
            res = [1] * (i + 1)
            for j in range(1, i):
                res[j] = results[i-1][j-1] + results[i-1][j]
            results.append(res)
        return results
  • 易错点：
  1. 不能用一维 dp 从左到右更新：dp[j-1] 被覆盖后，算 dp[j] 时拿到的是新值不是上一行的旧值。要么用二维（读旧行写新行），要么从右到左更新
  2. `[1] * (i+1)` 先把首尾的 1 都填好：中间部分再用上一行计算覆盖，省去了单独处理首尾的 if 判断
  3. `range(1, i)` 在 i=0 或 i=1 时是空范围：不会报错也不会执行，正好跳过没有中间元素的行
  • 复杂度：时间 O(n²)，空间 O(n²)（存储所有行）
