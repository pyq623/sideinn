第 29 题 删除链表的倒数第 N 个结点

LeetCode 19 Remove Nth Node From End of List

难度 中等 标签 链表 双指针 原题链接

题面

给你一个链表，删除链表的倒数第 n 个结点，并且返回链表的头结点。

示例 1：

输入： head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]

示例 2：

输入： head = [1], n = 1
输出：[]

示例 3：

输入： head = [1,2], n = 1
输出：[1]

提示：

  • 链表中结点的数目为 sz
  • 1 <= sz <= 30
  • 0 <= Node.val <= 100
  • 1 <= n <= sz

进阶： 你能尝试使用一趟扫描实现吗？

解法一 两次遍历

思路

  • 第一遍：遍历链表得到长度 length
  • 倒数第 n 个 = 正数第 length - n 个（从 0 开始），需要走到它的前一个，即从哨兵节点走 length - n 步
  • 改 cur.next = cur.next.next 删除目标节点

代码实现

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        length = 0
        cur = head
        while cur:
            length += 1
            cur = cur.next

        dum = ListNode(0, head)
        cur = dum
        for _ in range(length - n):
            cur = cur.next
        cur.next = cur.next.next
        return dum.next
  • 复杂度：时间 O(n)（两次遍历），空间 O(1)

解法二 快慢双指针 一次遍历

思路

  • 让 r 先走 n 步，然后 l 和 r 同步走，直到 r.next 为 None
  • 此时 l 正好在目标节点的前一个，改 l.next = l.next.next 即可
  • 为什么有效：r 比 l 超前 n 步，r 到尾时 l 距尾正好 n 步，即倒数第 n 个的前一个
  • 易错点：
  1. 为什么是 `while r.next` 而不是 `while r`：在草稿纸上画一下就清楚了——我们要让 l 停在目标节点的前一个。如果用 while r，r 会走到 None，此时 l 停在目标节点本身，无法删除。用 while r.next，r 停在最后一个节点，l 正好停在目标的前一个
  2. 必须用哨兵节点：如果要删的是头节点（n == length），l 需要指向哨兵才能改掉 dum.next，否则无法处理
  3. `l = r = dum` 三个变量指向同一个链表：任意一个修改 .next，整个链表都变了

代码实现

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        l = r = dum = ListNode(0, head)
        for _ in range(n):
            r = r.next
        while r.next:
            r = r.next
            l = l.next
        l.next = l.next.next
        return dum.next
  • 复杂度：时间 O(n)（一次遍历），空间 O(1)
