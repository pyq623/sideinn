第 93 题 最长回文子串

LeetCode 5 Longest Palindromic Substring

难度 中等 标签 多维动态规划 双指针 字符串 动态规划 原题链接

题面

给你一个字符串 s，找到 s 中最长的 回文 子串。

示例 1：

输入： s = "babad"
输出： "bab"
解释： "aba" 同样是符合题意的答案。

示例 2：

输入： s = "cbbd"
输出： "bb"

提示：

  • 1 <= s.length <= 1000
  • s 仅由数字和英文字母组成

思路

和前面的"网格 DP"完全不同。前面的题 dp[i][j] 表示走到坐标 (i,j) 的结果，这题 dp[i][j] 表示子串 s[i..j] 是不是回文。

不同路径/最小路径和

最长回文子串

dp 维度含义

网格坐标 (行, 列)

子串范围 (起点 i, 终点 j)

依赖方向

上方 + 左方

内部（dp[i+1][j-1]）

遍历顺序

从左上到右下

按子串长度从短到长

返回值

dp[m-1][n-1]

记录最长的 True 对应的子串

递推逻辑

s[i..j] 是回文的条件：

  1. 两头字母相等：s[i] == s[j]
  2. 去掉两头后内部也是回文：dp[i+1][j-1] == True（或者长度 ≤ 2 不需要检查内部）
s = "babad"

"bab" 是回文吗？
  s[0]=='b', s[2]=='b' ✓ 相等
  去掉两头 → s[1..1] = "a"，长度1，一定是回文 ✓
  → dp[0][2] = True

遍历顺序 为什么按长度从短到长

算 dp[i][j] 需要 dp[i+1][j-1]（更短的子串）。所以必须先把短子串算好，长子串才能用。

长度1：dp[0][0], dp[1][1], ... 全是 True（单字符都是回文）
长度2：dp[0][1], dp[1][2], ... 看 s[i]==s[j] 就行
长度3：dp[0][2], dp[1][3], ... 看 s[i]==s[j] 且 dp[i+1][j-1]
...

循环范围怎么算

for length in range(2, n + 1):          # 长度从 2 到 n
    for i in range(n - length + 1):     # 起点 i 的范围
        j = i + length - 1              # 终点 j

`j = i + length - 1`：子串从 i 开始、长度为 length，终点下标 = 起点 + 长度 - 1。

`range(n - length + 1)`：要求 j 不越界，即 i + length - 1 < n → i < n - length + 1。

s = "babad"（n=5），length=3
i 可取 0, 1, 2（即 range(5-3+1) = range(3)）
  i=0: j=2, 子串 "bab" ✓
  i=1: j=3, 子串 "aba" ✓
  i=2: j=4, 子串 "bad" ✓
  i=3: j=5 → 越界！所以不能取

代码实现

class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        max_length = 1
        start = 0
        dp = [[False] * n for _ in range(n)]

        for i in range(n):
            dp[i][i] = True
        for length in range(2, n+1):
            for i in range(n-length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    if length == 2 or dp[i+1][j-1] == True:
                        dp[i][j] = True
                        if length > max_length:
                            max_length = length
                            start = i

        return s[start: start+max_length]
  • 易错点：
  1. `max_length` 必须初始化为 1 不是 0：单字符本身就是长度 1 的回文。如果 n=1，不会进入 range(2, n+1) 循环，max_length=0 会导致返回空串
  2. 长度为 2 时特殊处理：length == 2 时 dp[i+1][j-1] = dp[i+1][i]，i+1 > i 不合法。所以长度为 2 只需判断 s[i] == s[j]
  3. 遍历顺序必须按长度从短到长：不能简单地 i 从小到大遍历，因为 dp[i][j] 依赖 dp[i+1][j-1]（更短的子串），必须先算短的
  4. 返回的是子串本身不是长度：需要用 start 和 max_length 记录位置，最后切片返回
  • 复杂度：时间 O(n²)，空间 O(n²)
