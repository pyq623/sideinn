第 06 题 三数之和

LeetCode 15 3Sum

难度 中等 标签 双指针 数组 排序 原题链接

题面

给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

注意： 答案中不可以包含重复的三元组

示例 1：

输入： nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。

示例 2：

输入： nums = [0,1,1]
输出：[]
解释： 唯一可能的三元组和不为 0 。

示例 3：

输入： nums = [0,0,0]
输出：[[0,0,0]]
解释： 唯一可能的三元组和为 0 。

提示：

  • 3 <= nums.length <= 3000
  • -105 <= nums[i] <= 105

思想：排序 + 双指针。固定 i，在 i 右侧用相向双指针找两数之和等于 -nums[i]。关键是去重：外层跳过相同的 i，内层找到解后跳过相同的 l 和 r。

解法

class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        n = len(nums)
        nums.sort() #返回值是none，直接使用nums
        res_list = list()
        for i in range(n):
            if nums[i] > 0:
                break
            if i > 0 and nums[i - 1] == nums[i]:
                continue # 后面是对于l和r的去重，这里是对于i的去重

            l = i + 1
            r = n - 1
            while l < r:
                if nums[i] + nums[l] + nums[r] == 0:
                    res_list.append([nums[i], nums[l], nums[r]])
                    while l < r and nums[l+1]==nums[l]:
                        l = l + 1
                    while l < r and nums[r - 1] == nums[r]:
                        r = r - 1
                    # 此时是已经三数相加等于0的情况，所以直接l和r都前进就好了，单一前进肯定没可能得到新的等于0
                    l = l + 1
                    r = r - 1
                elif nums[i] + nums[l] + nums[r] < 0:
                    l = l + 1
                else:
                    r = r - 1
        return res_list

语法要点

  • nums.sort()：原地排序，返回 None；sorted(nums) 返回新列表，原列表不变
  • 外层去重 if i > 0 and nums[i] == nums[i-1]：必须是 i > 0 而不是 nums[i] > 0，否则逻辑永远走不到
  • 内层去重用 while 而不是 if：连续重复可能不止一个
  • nums[i] > 0: break：排序后第一个数都大于 0，三数之和不可能等于 0，直接结束
