第 70 题 最小栈

LeetCode 155 Min Stack

难度 中等 标签 栈 设计 原题链接

题面

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类:

  • MinStack() 初始化堆栈对象。
  • void push(int val) 将元素val推入堆栈。
  • void pop() 删除堆栈顶部的元素。
  • int top() 获取堆栈顶部的元素。
  • int getMin() 获取堆栈中的最小元素。

示例 1:

输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：
[null,null,null,null,-3,null,0,-2]

解释：
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.

提示：

  • -231 <= val <= 231 - 1
  • pop、top 和 getMin 操作总是在 非空栈 上调用

push, pop, top, and getMin最多被调用 3 * 104 次

思路

核心难点 getMin 要 O 1

push/top/pop 用 list 就行，但 getMin 不能每次遍历找最小值。

解法 辅助栈同步记录当前最小值

用两个栈，主栈正常存数据，辅助栈每个位置存"主栈从底到这个位置的最小值"：

  • push 时：辅助栈.append(min(val, 辅助栈栈顶))
  • pop 时：两个栈同步 pop（不用判断）
  • getMin：直接返回辅助栈栈顶
push(-2): 主栈 [-2]       辅助栈 [-2]
push(0):  主栈 [-2,0]     辅助栈 [-2,-2]
push(-3): 主栈 [-2,0,-3]  辅助栈 [-2,-2,-3]
pop():    主栈 [-2,0]     辅助栈 [-2,-2]
getMin(): 辅助栈栈顶 = -2 ✓

Python list 作为栈的操作

  • push → stack.append(val)
  • pop → stack.pop()
  • top → stack[-1]

代码实现

class MinStack:

    def __init__(self):
        self.stack = []
        self.stack1 = []

    def push(self, value: int) -> None:
        self.stack.append(value)
        min_top = self.stack1[-1] if self.stack1 else inf
        self.stack1.append(min(min_top, value))

    def pop(self) -> None:
        self.stack.pop()
        self.stack1.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.stack1[-1]
