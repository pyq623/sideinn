第 72 题 每日温度

LeetCode 739 Daily Temperatures

难度 中等 标签 栈 数组 单调栈 原题链接

题面

给定一个整数数组 temperatures ，表示每天的温度，返回一个数组 answer ，其中 answer[i] 是指对于第 i 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 0 来代替。

示例 1:

输入: temperatures = [73,74,75,71,69,72,76,73]
输出:  [1,1,4,2,1,1,0,0]

示例 2:

输入: temperatures = [30,40,50,60]
输出:  [1,1,1,0]

示例 3:

输入: temperatures = [30,60,90]
输出:[1,1,0]

提示：

  • 1 <= temperatures.length <= 105
  • 30 <= temperatures[i] <= 100

思路

  • 用单调栈，O(n) 解决。栈里存的是"还没找到更高温度的那些天"的下标，从栈底到栈顶温度递减
  • 每来一个新温度，如果比栈顶高，说明"我就是栈顶那天等的更高温度"，弹出算距离，一直弹到栈顶不比我低为止

用 73 74 75 71 69 72 76 73 走一遍

i=0: 73  栈空，入栈                    栈：[0]
i=1: 74  74>73 → 弹出0，ans[0]=1-0=1   栈：[1]
i=2: 75  75>74 → 弹出1，ans[1]=2-1=1   栈：[2]
i=3: 71  71<75 → 入栈                  栈：[2, 3]
i=4: 69  69<71 → 入栈                  栈：[2, 3, 4]
i=5: 72  72>69 → 弹出4，ans[4]=5-4=1
         72>71 → 弹出3，ans[3]=5-3=2
         72<75 → 入栈                  栈：[2, 5]
i=6: 76  76>72 → 弹出5，ans[5]=6-5=1
         76>75 → 弹出2，ans[2]=6-2=4   栈：[6]
i=7: 73  73<76 → 入栈                  栈：[6, 7]

结束，栈里剩的（6,7）没有更高温度，ans 保持 0

ans = [1, 1, 4, 2, 1, 1, 0, 0] ✓

每个元素最多入栈一次出栈一次，所以总共 O(n)。

代码实现

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        stack = []
        ans = [0] * len(temperatures)
        for i, v in enumerate(temperatures):
            while stack and v > temperatures[stack[-1]]:
                tops = stack.pop()
                ans[tops] = i - tops
            stack.append(i)
        return ans
  • 易错点：
  1. `stack[-1]` 看一眼，`stack.pop()` 才取出来：判断条件时只 peek 不 pop，确定要弹了才 pop。在 if/while 条件里直接 stack.pop() 会误删栈顶
  2. 栈里存下标不是存温度值：因为算距离需要下标（i - tops）
  3. `ans` 初始化为 `[0] * n`：不能用空列表 []，否则 ans[idx] 越界。初始值 0 刚好对应"之后没有更高温度"的情况
  4. 是 `while` 不是 `if`：一个新温度可能比栈里多个元素都高（如 76 连续弹出 72 和 75），用 if 只弹一个会漏
  • 复杂度：时间 O(n)（每个元素最多入栈一次出栈一次），空间 O(n)（栈 + 结果数组）
