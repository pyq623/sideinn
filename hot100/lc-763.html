第 80 题 划分字母区间

LeetCode 763 Partition Labels

难度 中等 标签 贪心算法 贪心 哈希表 双指针 字符串 原题链接

题面

给你一个字符串 s 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 "ababcc" 能够被分为 ["abab", "cc"]，但类似 ["aba", "bcc"] 或 ["ab", "ab", "cc"] 的划分是非法的。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 s 。

返回一个表示每个字符串片段的长度的列表。

示例 1：

输入： s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：
划分结果为 "ababcbaca"、"defegde"、"hijhklij" 。
每个字母最多出现在一个片段中。
像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。

示例 2：

输入： s = "eccbbbbdec"
输出：[10]

提示：

  • 1 <= s.length <= 500
  • s 仅由小写英文字母组成

思路

和跳跃游戏 II（上一题）一模一样的模式！

跳跃游戏 II

划分字母区间

维护什么

当前这一跳的最远边界

当前片段的最远右边界

何时触发

i == cur_end 时跳一步，step++

i == fur_dis 时切一刀，记录长度

更新方式

max_reach = max(max_reach, i+nums[i])

fur_dis = max(fur_dis, last[s[i]])

"范围"来源

每个位置的跳跃距离 nums[i]

每个字母最后出现的位置 last[s[i]]

代码骨架完全一样：

# 跳跃游戏 II
for i in range(n - 1):
    max_reach = max(max_reach, i + nums[i])
    if i == cur_end:
        step += 1
        cur_end = max_reach

# 划分字母区间
for i in range(n):
    fur_dis = max(fur_dis, hash_dis[s[i]])
    if i == fur_dis:
        results.append(i + 1 - prev)
        prev = i + 1

都是"在遍历过程中不断推远边界，到达边界时做一次操作"的贪心模板。

两步走：

  1. 预处理：记录每个字母最后一次出现的位置
  2. 扫描：从左到右遍历，每个字母都把右边界推到它最后出现的位置。当 i == 右边界 时，说明当前片段内所有字母都不会再后面出现了，切一刀
s = "ababcbacadefegdehijhklij"

i=0 'a': a最后在8,  边界=8
i=1 'b': b最后在5,  边界=8
i=2 'a': 边界=8
...
i=8 'a': i==边界8, 切！第一段长度=9

i=9  'd': d最后在14, 边界=14
i=10 'e': e最后在15, 边界=15
...
i=15 'e': i==边界15, 切！第二段长度=7

i=16 'h': h最后在19, 边界=19
...
i=23 'j': i==边界23, 切！第三段长度=8

代码实现

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        results = []
        hash_dis = dict()
        n = len(s)
        fur_dis = 0
        prev = 0
        for i in range(n):
            hash_dis[s[i]] = i
        for i in range(n):
            fur_dis = max(fur_dis, hash_dis[s[i]])
            if i == fur_dis:
                results.append(i + 1 - prev)
                prev = i + 1
        return results
  • 易错点：
  1. `results[-1]` 是长度不是位置：算片段长度时不能用上一段的长度来减，要用 prev 记录当前片段的起始位置，长度 = i + 1 - prev
  2. `s[i]` 不是 `n[i]`：n 是整数（len(s)），不能下标取值
  3. 第一次遍历记录的是最后出现位置：hash_dis[s[i]] = i 会不断覆盖，最终保留的就是最后一次出现的下标
  4. 切完后 `prev = i + 1`：下一段从 i+1 开始
  • 复杂度：时间 O(n)（两次线性遍历），空间 O(1)（字母表大小固定 26）
