第 09 题 找到字符串中所有字母异位词

LeetCode 438 Find All Anagrams in a String

难度 中等 标签 滑动窗口 哈希表 字符串 原题链接

题面

给定两个字符串 s 和 p，找到 s 中所有 p 的 异位词 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

示例 1:

输入: s = "cbaebabacd", p = "abc"
输出:[0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

示例 2:

输入: s = "abab", p = "ab"
输出:[0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。

提示:

1 <= s.length, p.length <= 3 104

  • s 和 p 仅包含小写字母

解法一 定长滑动窗口

  • 思路
  • 异位词的本质：两个字符串中每种字母出现的次数相同
  • 使用定长滑动窗口（窗口大小固定为 len(p)），在 s 上滑动，每一步比较窗口内字符频率是否和 p 相同
  • 窗口每右移一步，右端字符加入计数，左端字符减去计数
  • 用 Counter 直接 == 比较即可判断是否为异位词
  • 代码实现
     from collections import Counter
class Solution:
        def findAnagrams(self, s: str, p: str) -> List[int]:
            cnt_p = Counter(p)
            cnt_s = Counter()  # 空的

            n_s = len(s)
            n_p = len(p)
            res = []
            for r_i, r_v in enumerate(s):
                cnt_s[s[r_i]] += 1 # 右边赋值

                l_i = r_i - n_p + 1
                if l_i < 0:  # 窗口长度不足 len(p)
                    continue
                if cnt_p == cnt_s:
                    res.append(l_i)
                cnt_s[s[l_i]] -= 1  # 左端点字母离开窗口
            return res
  • 复杂度：时间 O(N × 26)（每次 Counter 比较遍历 26 个字母），空间 O(26)

解法二 不定长滑动窗口

  • 思路
  • 用一个 cnt 初始化为 Counter(p)，表示"每种字母还需要多少个"
  • 右端字符进入窗口：cnt[r_v] -= 1，表示这个字符的需求减少了一个
  • 核心设计：如果右边新加入的字符使得窗口不合法（`cnt[r_v] < 0`，说明这个字符多了），左边就不断收缩，直到窗口重新合法
  • 收缩时 cnt[s[l]] += 1，表示把左端字符"还回去"，需求恢复
  • 当窗口大小恰好等于 len(p) 时，所有字符的 cnt 都 >= 0 且窗口长度刚好用完了所有需求，说明是异位词
  • 代码实现
    class Solution:
        def findAnagrams(self, s: str, p: str) -> List[int]:
            cnt = Counter(p)
            res = []
            l = 0
            for r_i, r_v in enumerate(s):
                cnt[r_v] -= 1
                while cnt[r_v] < 0:  # 当前字符多了，窗口不合法，收缩左边
                    cnt[s[l]] += 1
                    l += 1
                if r_i - l + 1 == len(p):
                    res.append(l)
            return res
  • 复杂度：时间 O(N)（每个字符最多进出窗口各一次），空间 O(26)
