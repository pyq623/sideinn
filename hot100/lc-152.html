第 88 题 乘积最大子数组

LeetCode 152 Maximum Product Subarray

难度 中等 标签 动态规划 数组 原题链接

题面

给你一个整数数组 nums ，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 32-位 整数。

请注意 ，一个只包含一个元素的数组的乘积是这个元素的值。

示例 1:

输入: nums = [2,3,-2,4]
输出: 6
解释:  子数组 [2,3] 有最大乘积 6。

示例 2:

输入: nums = [-2,0,-1]
输出: 0
解释:  结果不能为 2, 因为 [-2,-1] 不是子数组。

提示:

  • 1 <= nums.length <= 2 * 104
  • -10 <= nums[i] <= 10
  • nums 的任何子数组的乘积都 保证 是一个 32-位 整数

思路

和前面的题不同，这题有个特殊的坑：负数乘负数会变正数。所以不能只维护最大值，必须同时维护最大值和最小值。

  • max_dp[i]：以 nums[i] 结尾的连续子数组的最大乘积
  • min_dp[i]：以 nums[i] 结尾的连续子数组的最小乘积（可能是很大的负数，遇到下一个负数就翻正了）

每个位置有三个候选：

max_dp[i] = max(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
min_dp[i] = min(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
  • nums[i]：从当前位置重新开始
  • max_dp[i-1] * nums[i]：延续之前的最大乘积
  • min_dp[i-1] * nums[i]：之前最小的负数 × 当前负数 = 可能变最大
nums = [2, 3, -2, 4]

i=0: max=2,  min=2
i=1: max=6,  min=3
i=2: max=-2, min=-12  （6*-2=-12 很小，但留着备用）
i=3: max=4,  min=-48

全局最大 = max(max_dp) = 6

返回值为什么是 max maxdp 不是 maxdp n 1

dp[i] 的含义是"以 nums[i] 结尾的最优解"，但最终答案不一定以最后一个元素结尾，所以要取整个 dp 数组的最大值。

和最长递增子序列一样的原因。而爬楼梯/零钱兑换终点固定，可以直接返回 dp[n]。

为什么这题只看 i-1 不用遍历所有 j？ 因为子数组必须连续，以 nums[i] 结尾的子数组只能从 i-1 延伸过来（或者从 i 重新开始）。而子序列可以跳过中间元素，所以要遍历所有 j。

代码对比 单词拆分 与 乘积最大子数组

# 单词拆分（不连续切割，内层遍历所有 j）
for i in range(1, n + 1):
    for j in range(i):               # 遍历所有切割点
        if dp[j] and s[j:i] in set_w:
            dp[i] = True

# 乘积最大子数组（必须连续，只看 i-1）
for i in range(1, n):
    max_dp[i] = max(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
    min_dp[i] = min(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])

单词拆分需要内层循环是因为切割点 j 可以是任意位置；乘积最大子数组只看 i-1 是因为连续子数组只能从上一个位置延伸。

代码实现

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        n = len(nums)
        min_dp = [inf] * (n + 1)
        max_dp = [-inf] * (n + 1)
        min_dp[0] = nums[0]
        max_dp[0] = nums[0]
        for i in range(1, n):
            max_dp[i] = max(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
            min_dp[i] = min(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
        return max(max_dp[:n])
  • 易错点：
  1. 必须同时维护 min 和 max：只维护 max 会漏掉"负负得正"的情况
  2. 三个候选都要考虑：nums[i] 本身也是候选（代表从这里重新开始），不能只看 dp[i-1] * nums[i]
  3. 返回 `max(max_dp[:n])` 不是 `max_dp[n-1]`：最大乘积子数组可能在任何位置结尾（和最长递增子序列一样）
  4. `min_dp[i]` 用的是 `max_dp[i-1]` 不是 `max_dp[i]`：读的是上一个位置的值，所以两行顺序不影响正确性
  • 复杂度：时间 O(n)，空间 O(n)（可优化到 O(1)，只保留前一个值）
