第 35 题 LRU 缓存

LeetCode 146 LRU Cache

难度 中等 标签 链表 设计 哈希表 原题链接

题面

请你设计并实现一个满足 LRU (最近最少使用) 缓存 约束的数据结构。

实现 LRUCache 类：

  • LRUCache(int capacity) 以 正整数 作为容量 capacity 初始化 LRU 缓存
  • int get(int key) 如果关键字 key 存在于缓存中，则返回关键字的值，否则返回 -1 。
  • void put(int key, int value) 如果关键字 key 已经存在，则变更其数据值 value ；如果不存在，则向缓存中插入该组 key-value 。如果插入操作导致关键字数量超过 capacity ，则应该 逐出 最久未使用的关键字。

函数 get 和 put 必须以 O(1) 的平均时间复杂度运行。

示例：

输入
["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]
输出
[null, null, null, 1, null, -1, null, -1, 3, 4]

解释
LRUCache lRUCache = new LRUCache(2);
lRUCache.put(1, 1); // 缓存是 {1=1}
lRUCache.put(2, 2); // 缓存是 {1=1, 2=2}
lRUCache.get(1);    // 返回 1
lRUCache.put(3, 3); // 该操作会使得关键字 2 作废，缓存是 {1=1, 3=3}
lRUCache.get(2);    // 返回 -1 (未找到)
lRUCache.put(4, 4); // 该操作会使得关键字 1 作废，缓存是 {4=4, 3=3}
lRUCache.get(1);    // 返回 -1 (未找到)
lRUCache.get(3);    // 返回 3
lRUCache.get(4);    // 返回 4

提示：

  • 1 <= capacity <= 3000
  • 0 <= key <= 10000
  • 0 <= value <= 105
  • 最多调用 2 * 105 次 get 和 put

思路

数据结构选择

  • 哈希表 + 双向链表：哈希表实现 O(1) 查找，双向链表维护使用顺序（越靠近尾部越新，头部是最久未使用的）
  • 为什么是双向链表而不是单向？因为核心操作是"把一个节点从中间摘出来移到尾部"。摘出需要修改前驱的 next，单向链表只能 O(n) 遍历找前驱，双向链表通过 node.prev 直接 O(1) 拿到

设计要点

  • 自定义 ListNode：需要同时存 key 和 val。存 key 是因为淘汰时需要从 dict 中 pop 对应的 key
  • 哨兵节点 head/tail：避免处理边界情况（空链表、只有一个节点等），所有操作都可以统一处理
  • 初始化时 head 和 tail 必须互连：head.next = tail，tail.prev = head，否则初始状态下 tail.prev 是 None，插入第一个节点时会崩

三个操作的逻辑

  1. move_to_tail(key)：先从当前位置摘出，再插到 tail 前面
  2. get(key)：dict 中找到就移到尾部并返回 val，找不到返回 -1
  3. put(key, value)：
  • key 已存在：更新 val + move_to_tail
  • key 不存在：如果满了先淘汰 head.next，然后无论是否淘汰都要新增节点

指针操作的顺序原则

这道题最容易出错的地方就是指针赋值顺序。核心原则：先用旧值做完所有事，再改变它

  • 插入到 tail 前面（move_to_tail 和 put 新增都用到）：
    node.prev = self.tail.prev      # 先设置 node 的指针
    node.next = self.tail
    self.tail.prev.next = node      # 先让旧的 tail.prev 指向 node
    self.tail.prev = node           # 最后才改 tail.prev
如果先写 `self.tail.prev = node`，则 `self.tail.prev.next` 变成 `node.next`，改错了
  • 淘汰 head.next：
    self.head.next = self.head.next.next  # 先跳过被删节点
    self.head.next.prev = self.head       # 再让新的 head.next 指回 head
如果先写 `self.head.next.prev = self.head`——这没意义，因为 head.next.prev 本来就是 head

易错点总结

  1. ListNode 的 `__init__` 需要默认参数：head/tail 创建时不传参，没有默认值会报错
  2. `self.capacity = capacity`：别写成 = 0
  3. head/tail 必须初始连接：否则第一次插入时 self.tail.prev.next 会对 None 操作
  4. get 用 `dict.get(key)` 不是 `dict[key]`：key 不存在时前者返回 None，后者 KeyError
  5. put 已有 key 时别忘了 move_to_tail：只更新 val 不移动会导致 LRU 顺序错误
  6. put 新增节点不能放在 else 里：淘汰和新增是先后关系，不是互斥关系。淘汰后也要新增
  7. 淘汰时别忘了 `dict.pop`：光断链表不清 dict，后续查找会找到野节点
  8. `dict.pop(key)` 不是 `dict[key].pop()`：前者是从字典删 key，后者是在 ListNode 上调 pop（报错）
  9. `append` ≠ `heappush`（如果用堆的话）：append 不维护堆序

代码实现

class ListNode:
    def __init__(self, key=0, val=0):
        self.val = val
        self.key = key
        self.prev = None
        self.next = None

class LRUCache:

    def __init__(self, capacity: int):
        self.capacity = capacity
        self.hast_dict = dict()
        self.head = ListNode()
        self.tail = ListNode()
        self.head.next = self.tail
        self.tail.prev = self.head

    def move_to_tail(self, key):
        node = self.hast_dict[key]
        # 从当前位置摘出
        node.prev.next = node.next
        node.next.prev = node.prev
        # 插到 tail 前面
        node.prev = self.tail.prev
        node.next = self.tail
        # 要先写这个长的，不然先写 self.tail.prev = node的话，tail.prev已经改变了
        self.tail.prev.next = node
        self.tail.prev = node

    def get(self, key: int) -> int:
        node = self.hast_dict.get(key)
        if node:
            self.move_to_tail(node.key)
            return node.val
        else:
            return -1

    def put(self, key: int, value: int) -> None:
        if key in self.hast_dict:
            self.hast_dict[key].val = value
            self.move_to_tail(key)
        else:
            if len(self.hast_dict) == self.capacity:
                # 弹出头部的节点
                self.hast_dict.pop(self.head.next.key)
                # 先将下一个节点更新
                self.head.next = self.head.next.next
                # 此时再将下一个节点指向head节点
                self.head.next.prev = self.head
                # 如果先 self.head.next.prev =  self.head 这就没意义，因为此时本来就是head

            self.hast_dict[key] = ListNode(key=key, val=value)
            node = self.hast_dict[key]
            node.prev = self.tail.prev
            node.next = self.tail
            self.tail.prev.next = node
            self.tail.prev = node
  • 复杂度：时间 get/put 均 O(1)，空间 O(capacity)
