第 68 题 寻找两个正序数组的中位数

LeetCode 4 Median of Two Sorted Arrays

难度 困难 标签 二分查找 数组 分治 原题链接

题面

给定两个大小分别为 m 和 n 的正序（从小到大）数组 nums1 和 nums2。请你找出并返回这两个正序数组的 中位数 。

算法的时间复杂度应该为 O(log (m+n)) 。

示例 1：

输入： nums1 = [1,3], nums2 = [2]
输出： 2.00000
解释： 合并数组 = [1,2,3] ，中位数 2

示例 2：

输入： nums1 = [1,2], nums2 = [3,4]
输出： 2.50000
解释： 合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5

提示：

  • nums1.length == m
  • nums2.length == n
  • 0 <= m <= 1000
  • 0 <= n <= 1000
  • 1 <= m + n <= 2000
  • -106 <= nums1[i], nums2[i] <= 106

思路

核心思想

中位数本质上是把两个数组合在一起，切一刀，分成左右两半。只需要在较短的数组上二分，确定它贡献几个元素到左半部分，另一个数组的贡献数量自动确定。

与普通二分的关键区别

这道题的 `left`、`right`、`i`、`j` 都不是索引，而是"数量"。

  • i = nums1 贡献几个元素到左半部分，范围 [0, m]
  • j = half - i = nums2 贡献几个元素到左半部分
  • half = (m+n+1)//2 = 左半部分总共要几个元素（+1 是为了奇数时中位数归入左半）
  • 因为是数量不是索引，所以 right = m（不是 m-1），代表 nums1 全部贡献的情况
i=0:  [ | 1, 3, 5]     贡献 0 个
i=1:  [1 | 3, 5]       贡献 1 个
i=2:  [1, 3 | 5]       贡献 2 个
i=3:  [1, 3, 5 | ]     贡献 3 个（全部）

为什么 n1leftmax 用 nums1 i 1

因为 i 是数量，所以左半的最后一个元素下标是 i-1。同理右半第一个元素下标是 i。

判断条件 交叉比较

同数组内部天然有序不用比，只需检查交叉的两对：

  • n1_left_max > n2_right_min → nums1 切多了，往左移（right = i - 1）
  • n2_left_max > n1_right_min → nums1 切少了，往右移（left = i + 1）
  • 都满足 → 找到正确切割位置

边界处理

当 i=0、i=m、j=0、j=n 时，某一侧不存在元素，用极值替代让比较条件自动成立：

  • 左边没元素 → -inf（不可能比任何数大）
  • 右边没元素 → inf（不可能比任何数小）

为什么要保证 nums1 是较短数组

j = half - i，而 j 必须在 [0, n] 范围内：

  • 当 i = 0 时，j = half，需要 half <= n
  • 当 i = m 时，j = half - m，需要 half - m >= 0

只有 nums1 是较短的那个（m <= n）时，这两个条件才一定满足。如果 nums1 更长，i=0 时 j = half 就可能超过 n，直接越界。

所以开头那个 swap 不是优化，是正确性保证。

返回值区分奇偶

  • 奇数：左半最大值 max(n1_l_max, n2_l_max)
  • 偶数：(左半最大 + 右半最小) / 2

代码实现

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        m = len(nums1)
        n = len(nums2)
        if m > n:
            return self.findMedianSortedArrays(nums2, nums1)
        left, right = 0, m # 这里的left 和 right不再是索引，而是数量
        half = (m + n + 1) // 2
        while left <= right:
            i = (left + right) // 2 # 这里的i 也是数量
            j = half - i
            n1_l_max = nums1[i-1] if i > 0 else -inf
            n1_r_min = nums1[i] if i < m else inf
            n2_l_max = nums2[j-1] if j > 0 else -inf
            n2_r_min = nums2[j] if j < n else inf
            if n1_l_max > n2_r_min:
                right = i - 1
            elif n2_l_max > n1_r_min:
                left = i + 1
            else:
                if (m+n) % 2 == 0:
                    res = (max(n1_l_max, n2_l_max) + min(n2_r_min, n1_r_min)) / 2
                else:
                    res = max(n1_l_max, n2_l_max)
                return res
