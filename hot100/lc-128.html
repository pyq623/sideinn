第 03 题 最长连续序列

LeetCode 128 Longest Consecutive Sequence

难度 中等 标签 哈希 数组 哈希表 原题链接

题面

给定一个未排序的整数数组 nums ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 O(n) 的算法解决此问题。

示例 1：

输入： nums = [100,4,200,1,3,2]
输出： 4
解释： 最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。

示例 2：

输入： nums = [0,3,7,2,5,8,4,6,0,1]
输出： 9

示例 3：

输入： nums = [1,0,1,2]
输出： 3

提示：

  • 0 <= nums.length <= 105
  • -109 <= nums[i] <= 109

思想：

解法

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        set_num = set(nums)
        ans = 0
        for sn in set_num:
            less_sn = sn - 1
            if less_sn in set_num:
                continue  # skip, so only forward when least sequence
            more_sn = sn + 1
            while more_sn in set_num:
                more_sn = more_sn + 1
            ans = max(ans, more_sn - sn)
        return ans

语法要点

  • set(nums)：将列表转为哈希集合，自动去重，且 in 查询为 O(1)
  • 两层循环但总时间 O(n)：if x-1 in set: continue 保证 while 只从序列起点触发，每个元素最多被 while 访问一次
  • max(ans, more_sn - sn)：more_sn 停在第一个不在集合中的数，所以序列长度是 more_sn - sn
  • for sn in set_num 这个一定要是在set_num这个去重集合里循环，不然会出现超时
  • ans = 0 放在了 for 循环里面，每轮都重置为 0，所以一定要放在 for 循环外面
