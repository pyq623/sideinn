第 15 题 轮转数组

LeetCode 189 Rotate Array

难度 中等 标签 普通数组 数组 数学 双指针 原题链接

题面

给定一个整数数组 nums，将数组中的元素向右轮转 k 个位置，其中 k 是非负数。

示例 1:

输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释:
向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]

示例 2:

输入： nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释:
向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]

提示：

  • 1 <= nums.length <= 105
  • -231 <= nums[i] <= 231 - 1
  • 0 <= k <= 105

进阶：

  • 尽可能想出更多的解决方案，至少有 三种 不同的方法可以解决这个问题。
  • 你可以使用空间复杂度为 O(1) 的 原地 算法解决这个问题吗？

思路

  • 三次翻转法：
  • 向右轮转 k 位，等价于把数组最后 k 个元素搬到前面。可以通过三次翻转实现：
  1. 整体翻转：[1,2,3,4,5,6,7] → [7,6,5,4,3,2,1]
  2. 翻转前 k 个：[7,6,5,4,3,2,1] → [5,6,7,4,3,2,1]
  3. 翻转剩余部分：[5,6,7,4,3,2,1] → [5,6,7,1,2,3,4]
  • 为什么要先 k % n：当 k >= n 时，轮转 n 次等于没转，所以取模去掉多余的整圈
  • 易错点：
  1. `k % n` 不是 `nums % k`：是对长度取模，不是对列表取模，列表不能做 % 运算
  2. 第三个 reverse 起始是 `mod_num` 不是 `mod_num - 1`：前 k 个是 [0, mod_num-1]，剩余部分是 [mod_num, n-1]，不能重叠
  3. 缩进问题：n = len(nums) 等主逻辑代码必须和 def reverse 同级，不能缩进到 reverse 函数体内，否则变成了 reverse 的一部分而非 rotate 的主逻辑

代码实现

class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        def reverse(i: int, j: int):
            while i < j:
                nums[i], nums[j] = nums[j], nums[i]
                i = i + 1
                j = j - 1

        n = len(nums)
        mod_num = k % n
        reverse(0, n - 1)
        reverse(0, mod_num - 1)
        reverse(mod_num, n - 1)
  • 复杂度：时间 O(N)，空间 O(1)（原地操作）

解法二 双端队列

  • deque.rotate(k) 直接把右边 k 个元素搬到左边，正好是轮转的语义
  • nums[:] = d 是原地替换列表内容（不是新建列表），满足题目要求的原地修改
  • 空间 O(N)，不满足进阶要求，但写法最直觉
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        d = collections.deque(nums)
        d.rotate(k)
        nums[:] = d
        return nums
  • 复杂度：时间 O(N)，空间 O(N)
