第 12 题 最小覆盖子串

LeetCode 76 Minimum Window Substring

难度 困难 标签 子串 哈希表 字符串 滑动窗口 原题链接

题面

给定两个字符串 s 和 t，长度分别是 m 和 n，返回 s 中的 最短窗口 子串，使得该子串包含 t 中的每一个字符（包括重复字符 ）。如果没有这样的子串，返回空字符串 ""。

测试用例保证答案唯一。

示例 1：

输入： s = "ADOBECODEBANC", t = "ABC"
输出： "BANC"
解释： 最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

示例 2：

输入： s = "a", t = "a"
输出： "a"
解释： 整个字符串 s 是最小覆盖子串。

示例 3:

输入: s = "a", t = "aa"
输出: ""
解释: t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。

提示：

  • m == s.length
  • n == t.length
  • 1 <= m, n <= 105
  • s 和 t 由英文字母组成

进阶： 你能设计一个在 O(m + n) 时间内解决此问题的算法吗？

思路

  • 滑动窗口：右指针不断扩展，当窗口满足覆盖条件时，收缩左指针寻找更短的窗口
  • 用两个 Counter 分别统计窗口内和 t 的字符频率，cnt_s >= cnt_t 即可 O(1) 判断是否覆盖（Python 的 Counter 比较：对 cnt_t 中每个 key，cnt_s[key] >= cnt_t[key]）
  • 易错点：
  1. `cnt_s[s[left]]` 不是 `cnt_s[left]`：left 是下标不是字符，要用 s[left] 取对应字符
  2. 切片要 `ans_right + 1`：ans_right 是窗口右端点的下标，Python 切片不包含右端，所以是 s[ans_left: ans_right + 1]
  3. 没找到时要返回空字符串：不能漏掉 else: return ""

代码实现

class Solution:
    def minWindow(self, s: str, t: str) -> str:
        cnt_s = Counter()
        cnt_t = Counter(t)

        left = 0
        ans_left, ans_right = -1, len(s)
        for right, right_v in enumerate(s):
            cnt_s[right_v] += 1 # 右端点
            while cnt_s >= cnt_t:  # 窗口已覆盖 t，尝试收缩左边
                if right - left < ans_right - ans_left:
                    ans_left = left
                    ans_right = right
                cnt_s[s[left]] -= 1  # 注意是 s[left] 不是 left
                left += 1

        if ans_left != -1:
            return s[ans_left: ans_right + 1]  # 切片要 +1
        else:
            return ""
  • 复杂度：时间 O(m + n)（每个字符最多进出窗口各一次），空间 O(|Σ|)（字符集大小）
