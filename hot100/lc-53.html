第 13 题 最大子数组和

LeetCode 53 Maximum Subarray

难度 中等 标签 普通数组 数组 分治 动态规划 原题链接

题面

给你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组 是数组中的一个连续部分。

示例 1：

输入： nums = [-2,1,-3,4,-1,2,1,-5,4]
输出： 6
解释： 连续子数组 [4,-1,2,1] 的和最大，为 6 。

示例 2：

输入： nums = [1]
输出： 1

示例 3：

输入： nums = [5,4,-1,7,8]
输出： 23

提示：

  • 1 <= nums.length <= 105
  • -104 <= nums[i] <= 104

进阶： 如果你已经实现复杂度为 O(n) 的解法，尝试使用更为精妙的 分治法 求解。

思路

  • 动态规划
  • 定义 dp[i] = 以 nums[i] 为结尾的最大子数组和
  • 转移逻辑：对于每个位置 i，要么接上前面的子数组（dp[i-1] + nums[i]），要么从自己重新开始（nums[i]）
  • 如果 dp[i-1] < 0：前面的和是负贡献，不如从 nums[i] 重新开始，dp[i] = nums[i]
  • 如果 dp[i-1] >= 0：前面的和是正贡献，接上更好，dp[i] = dp[i-1] + nums[i]
  • 最终答案 = 所有 dp[i] 中的最大值
  • 为什么不能用滑动窗口？因为数组含负数，无法保证收缩左边界会让和减小

代码实现

class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        dp_n = [0] * len(nums)
        # dp_n = [0 for _ in range(len(nums))]
        res = nums[0]
        dp_n[0] = nums[0]
        for i in range(1, len(nums)):
            if dp_n[i-1] < 0:
                dp_n[i] = nums[i]
            else:
                dp_n[i] = dp_n[i-1] + nums[i]
            res = res if dp_n[i] < res else dp_n[i]
        return res
  • 复杂度：时间 O(N)，空间 O(N)

写法二 空间优化

  • 由于 dp[i] 只依赖 dp[i-1]，用一个变量 pre 代替整个数组即可
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        pre = nums[0]
        res = pre
        for i in range(1, len(nums)):
            if pre < 0:
                pre = nums[i]
            else:
                pre = pre + nums[i]
            res = res if pre < res else pre
        return res
  • 复杂度：时间 O(N)，空间 O(1)

写法三 分治法

class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        def divide(left, right):
            # 区间中只剩一个数字
            if left == right:
                return nums[left]
            mid = (left + right) // 2
            # 情况一：最大子数组完全在左半边
            left_max = divide(left, mid)
            # 情况二：最大子数组完全在右半边
            right_max = divide(mid + 1, right)
            # 情况三：最大子数组跨过中间
            total = 0
            best_left_sum = float("-inf")
            # 找到以 nums[mid] 结尾的最大连续和
            for i in range(mid, left - 1, -1):
                total += nums[i]
                best_left_sum = max(best_left_sum, total)
            total = 0
            best_right_sum = float("-inf")
            # 找到以 nums[mid + 1] 开头的最大连续和
            for i in range(mid + 1, right + 1):
                total += nums[i]
                best_right_sum = max(best_right_sum, total)
            cross_max = best_left_sum + best_right_sum
            return max(left_max, right_max, cross_max)
        return divide(0, len(nums) - 1)

为什么左右两边使用递归？

左半边的最大子数组不一定占满整个左半边，它的起点、终点和长度都不知道。右半边也是如此。

这两个问题和原问题完全相同，只是数组区间变小了，所以适合继续调用 `divide`。

为什么跨中间可以直接计算？

跨中间的子数组必须由两部分组成：

```text

以 nums[mid] 结尾的左侧最大连续和

+

以 nums[mid + 1] 开头的右侧最大连续和

```

中间位置提供了锚点，所以不需要猜测任意起点和终点：

  • 从 `mid` 开始向左扫描，找出最好的左半段。
  • 从 `mid + 1` 开始向右扫描，找出最好的右半段。
  • 把两部分相加，得到 `cross_max`。

分治法复杂度

- 时间复杂度：`O(n log n)`。每层递归扫描的元素总数为 `O(n)`，递归树大约有 `log n` 层。

- 递归栈空间复杂度：`O(log n)`。
