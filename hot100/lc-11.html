第 05 题 盛最多水的容器

LeetCode 11 Container With Most Water

难度 中等 标签 双指针 贪心 数组 原题链接

题面

给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

说明： 你不能倾斜容器。

示例 1：

输入：[1,8,6,2,5,4,8,3,7]
输出： 49
解释： 图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。

示例 2：

输入： height = [1,1]
输出： 1

提示：

  • n == height.length
  • 2 <= n <= 105
  • 0 <= height[i] <= 104

思想：双指针从两端向中间收窄。面积 = min(h[i], h[j]) × (j-i)，每轮移动短板一侧的指针。

为什么移动短板？底边必然缩短 1，若移动长板，短板不变或变小，面积一定变小；若移动短板，短板可能变大，面积可能增大。

正确性：假设 h[i] < h[j]，移动 i 相当于跳过 S(i,j-1), S(i,j-2)...S(i,i+1) 这些状态——它们的短板 ≤ h[i] 且底边更窄，面积必然 < S(i,j)，不会丢失最大值。

解法

class Solution:
    def maxArea(self, height: List[int]) -> int:
        i, j, res = 0, len(height) - 1, 0
        while i < j:
            if height[i] < height[j]:
                res = max(res, (j - i) * height[i])
                i = i + 1
            else:
                res = max(res, (j - i) * height[j])
                j = j - 1
        return res

语法要点

  • i, j, res = 0, len(height) - 1, 0：Python 多变量同时赋值
  • while i < j：相向双指针的标准循环条件
  • 时间复杂度 O(n)，空间复杂度 O(1)
