第 58 题 组合总和

LeetCode 39 Combination Sum

难度 中等 标签 回溯 数组 原题链接

题面

给你一个 无重复元素 的整数数组 candidates 和一个目标整数 target ，找出 candidates 中可以使数字和为目标数 target 的 所有 不同组合 ，并以列表形式返回。你可以按 任意顺序 返回这些组合。

candidates 中的 同一个 数字可以 无限制重复被选取 。如果至少一个数字的被选数量不同，则两种组合是不同的。

对于给定的输入，保证和为 target 的不同组合数少于 150 个。

示例 1：

输入： candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：
2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。
7 也是一个候选， 7 = 7 。
仅有这两种组合。

示例 2：

输入: candidates = [2,3,5], target = 8
输出:[[2,2,2,2],[2,3,3],[3,5]]

示例 3：

输入: candidates = [2], target = 1
输出:[]

提示：

  • 1 <= candidates.length <= 30
  • 2 <= candidates[i] <= 40
  • candidates 的所有元素 互不相同
  • 1 <= target <= 40

思路

  • 本质是子集（第 56 题）的变体，不是前缀和。区别只有两点：允许重复选 + 加 sum 剪枝

和子集的对比

# 子集：每个元素最多选 1 次
def dfs(start, path):
    self.res.append(path[:])        # 每个节点都收集
    for i in range(start, n):
        path.append(nums[i])
        dfs(i + 1, path)            # i+1：不能再选自己
        path.pop()

# 组合总和：每个元素可以重复选
def dfs(start, path, cur_sum):
    if cur_sum == target:           # 和为 target 才收集
        self.res.append(path[:])
        return
    if cur_sum > target:            # 剪枝：超了就不继续
        return
    for i in range(start, n):
        path.append(candidates[i])
        dfs(i, path, cur_sum + candidates[i])   # i：还能选自己
        path.pop()

子集（第 56 题）

组合总和（本题）

每个元素能选几次

最多 1 次

无限次

递归传什么

dfs(i + 1, ...)

dfs(i, ...)（还能选自己）

收集时机

每个节点都收集

cur_sum == target 时收集

终止条件

for 范围空自然返回

cur_sum > target 剪枝

为什么用 start 不回头

和子集一样的道理：[2,3] 和 [3,2] 算同一个组合，用 start 保证只往后选，天然避免重复。

决策树 candidates 2 3 6 7 target 7

                         []  sum=0
               /          |        \        \
             [2]         [3]      [6]      [7] ✓
            / | \        / \        |
        [2,2] [2,3] [2,6]✗ [3,3] [3,6]✗  [6,6]✗
        /  \     |          |
   [2,2,2] [2,2,3]✓ [2,3,3]✗ [3,3,3]✗
      |
  [2,2,2,2]✗（sum=8>7，剪枝）

代码实现

class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        self.res = []
        n = len(candidates)
        def dfs(start, path, cur_sum):
            if cur_sum == target:
                self.res.append(path[:])
                return
            if cur_sum > target:
                return
            for i in range(start, n):
                path.append(candidates[i])
                dfs(i, path, cur_sum + candidates[i])
                path.pop()
        path = []
        dfs(0, path, 0)
        return self.res
  • 易错点：
  1. `dfs(i, ...)` 不是 `dfs(i + 1, ...)`：允许重复选同一个元素，传 i 而不是 i + 1
  2. `self.res.append(path[:])` 不是 `append(path)`：list 是可变类型，不复制后续 pop 会改掉
  3. 需要 `start` 参数：虽然可以重复选，但不能回头选前面的数（否则 [2,3] 和 [3,2] 重复）
  4. `cur_sum > target` 要 return：剪枝，否则会无限递归下去（因为可以无限选）
  • 复杂度：时间 O(n^T/M)（n 为候选数个数，T 为 target，M 为最小候选数），空间 O(T/M)（递归深度）
