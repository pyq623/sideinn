第 26 题 环形链表 II

LeetCode 142 Linked List Cycle II

难度 中等 标签 链表 哈希表 双指针 原题链接

题面

给定一个链表的头节点 head ，返回链表开始入环的第一个节点。 如果链表无环，则返回 null。

如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置（索引从 0 开始）。如果 pos 是 -1，则在该链表中没有环。注意：pos 不作为参数进行传递，仅仅是为了标识链表的实际情况。

不允许修改 链表。

示例 1：

输入： head = [3,2,0,-4], pos = 1
输出： 返回索引为 1 的链表节点
解释： 链表中有一个环，其尾部连接到第二个节点。

示例 2：

输入： head = [1,2], pos = 0
输出： 返回索引为 0 的链表节点
解释： 链表中有一个环，其尾部连接到第一个节点。

示例 3：

输入： head = [1], pos = -1
输出： 返回 null
解释： 链表中没有环。

提示：

  • 链表中节点的数目范围在范围 [0, 104] 内
  • -105 <= Node.val <= 105
  • pos 的值为 -1 或者链表中的一个有效索引

进阶： 你是否可以使用 O(1) 空间解决此题？

思路

第一次相遇 确认有环

  • fast 每轮走 2 步，slow 每轮走 1 步
  • 若 fast 走到 None，说明无环，返回 null
  • 若有环，fast 每轮比 slow 多走 1 步，间距不断缩小，一定会追上并相遇

设链表头到环入口有 a 个节点，环长为 b，相遇时两指针走步数分别为 f 和 s：

$f = 2s \quad \text（fast 是 slow 的 2 倍）$

$f = s + nb \quad \text（fast 比 slow 多走了整数圈）$

两式相减得：s = nb，f = 2nb

即第一次相遇时，slow 恰好走了 n 圈环的长度。

第二次相遇 找到环入口

  • 从链表头走到环入口需要 a 步
  • 从任意位置走到环入口，步数满足 k = a + nb（先走 a 步到入口，之后每绕一圈还会回到入口）
  • 此时 slow 已走了 nb 步，只需再走 `a` 步就到入口
  • 但 a 未知——让 fast 重新从 head 出发，和 slow 同步每次走 1 步：
  • fast 走 a 步时到达入口
  • slow 走 a 步时到达 a + nb = 入口
  • 两者恰好在环入口重合

代码实现

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        fast, slow = head, head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if fast == slow:
                break
        if not fast or not fast.next:
            return None
        fast = head
        while fast != slow:
            fast = fast.next
            slow = slow.next
        return fast
  • 易错点：第一个循环后必须判断是否真的有环。循环可能因为 fast 或 fast.next 为 None（无环）而自然退出，而不是走 break（有环）。如果不加 if not fast or not fast.next: return None，无环时 fast == slow == head，第二个循环直接不进入，错误地返回了 head 而不是 None
  • 复杂度：时间 O(n)，空间 O(1)
