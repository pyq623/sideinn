题面

你这个学期必须选修 numCourses 门课程，记为 0 到 numCourses - 1 。

在选修某些课程之前需要一些先修课程。 先修课程按数组 prerequisites 给出，其中 prerequisites[i] = [ai, bi] ，表示如果要学习课程 ai 则 必须 先学习课程 bi 。

  • 例如，先修课程对 [0, 1] 表示：想要学习课程 0 ，你需要先完成课程 1 。

请你判断是否可能完成所有课程的学习？如果可以，返回 true ；否则，返回 false 。

示例 1：

输入： numCourses = 2, prerequisites = [[1,0]]
输出： true
解释： 总共有 2 门课程。学习课程 1 之前，你需要完成课程 0 。这是可能的。

示例 2：

输入： numCourses = 2, prerequisites = [[1,0],[0,1]]
输出： false
解释： 总共有 2 门课程。学习课程 1 之前，你需要先完成​课程 0 ；并且学习课程 0 之前，你还应先完成课程 1 。这是不可能的。

提示：

  • 1 <= numCourses <= 2000
  • 0 <= prerequisites.length <= 5000
  • prerequisites[i].length == 2
  • 0 <= ai, bi < numCourses
  • prerequisites[i] 中的所有课程对 互不相同

思路

  • 本质问题：[1, 0] 表示"修 1 之前要先修 0"，即有向边 0 → 1。如果出现环（比如 0→1→0，互为前置），就永远修不完。所以题目就是：有向图是否有环？

数据结构怎么构造

这是本题最关键的一步——需要两个数据结构：

1. 邻接表 `graph`：记录"修完我之后能解锁谁"

graph = defaultdict(list)
for cur, pre in prerequisites:
    graph[pre].append(cur)    # pre 修完后能解锁 cur

# prerequisites = [[1,0], [2,0], [3,1], [3,2]]
# graph = {0: [1, 2], 1: [3], 2: [3]}
  • 为什么用 defaultdict(list)：查一个不存在的 key 时自动返回空列表，不会报错
  • 为什么不用其他结构：邻接表能 O(1) 查到"某门课能解锁哪些课"，BFS 时直接查 graph[node] 就行，不用遍历所有节点去找

2. 入度数组 `indegree`：记录"每门课还有几个前置没修"

indegree = [0] * numCourses
for cur, pre in prerequisites:
    indegree[cur] += 1    # cur 被指了一次，入度 +1

# prerequisites = [[1,0], [2,0], [3,1], [3,2]]
# indegree = [0, 1, 1, 2]
#             ↑ 入度为 0，可以直接修
  • 入度为 0 = 没有前置要求 = 可以直接修 = BFS 的起点
  • 建图和统计入度在同一个循环里完成

BFS 拓扑排序 入度法

  1. 建图 + 算入度：一次遍历 prerequisites 完成
  2. 入度为 0 的课程入队：遍历 indegree 找起点
  3. BFS 逐轮修课：修完一门课，把它能解锁的课程入度 -1。入度变 0 就入队
  4. 判断：最后所有课程入度都为 0 → 无环 → true

完整流程走一遍

prerequisites = [[1,0], [2,0], [3,1], [3,2]]
graph:     0 → [1, 2],  1 → [3],  2 → [3]
indegree:  [0, 1, 1, 2]
            ↑ 入队

第一轮：queue = [0]
  修课程 0 → graph[0] = [1, 2]
    课程 1 入度 1→0 ✅ 入队
    课程 2 入度 1→0 ✅ 入队

第二轮：queue = [1, 2]
  修课程 1 → graph[1] = [3]
    课程 3 入度 2→1 ❌ 还没到 0
  修课程 2 → graph[2] = [3]
    课程 3 入度 1→0 ✅ 入队

第三轮：queue = [3]
  修课程 3 → graph[3] = []

所有入度为 0 → true

为什么有环就修不完

0 → 1 → 0（环）
indegree: [1, 1]    # 都不为 0，没有课能入队
queue = []           # BFS 直接结束
indegree 里还有非 0 的 → false

环上的每个节点入度至少为 1，永远不会变成 0，永远入不了队

代码实现

class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        graph = defaultdict(list)
        indegree = [0] * (numCourses)
        for [cur, pre] in prerequisites:
            graph[pre].append(cur)
            indegree[cur] += 1

        queue = []
        for i in range(numCourses):
            if indegree[i] == 0:
                queue.append(i)
        while queue:
            tmp = []
            for node in queue:
                for node_next in graph[node]:
                    # 以它为前置条件的都可以过了
                    indegree[node_next] -= 1
                    if indegree[node_next] == 0:
                        tmp.append(node_next)

            queue = tmp
        flag = True
        for i in range(numCourses):
            if indegree[i] != 0:
                flag = False
                return flag
        return flag
  • 易错点：
  1. 邻接表的方向别搞反：graph[pre].append(cur) 是 pre → cur（修完 pre 能解锁 cur），不是反过来
  2. 入度统计的是 `cur` 不是 `pre`：indegree[cur] += 1，cur 是被指向的那个
  3. 入度 -1 后要立即判断是否为 0：等于 0 才入队，不是小于等于 0
  4. 最终判断是看 indegree 而不是 queue：queue 为空只说明 BFS 结束，不代表所有课都修完了。要检查是否所有入度都为 0
  • 复杂度：时间 O(V + E)（V 为课程数，E 为依赖关系数），空间 O(V + E)（邻接表 + 入度数组 + 队列）
