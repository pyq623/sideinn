附录四 while 循环终止条件 left 小于 right 与 left 小于等于 right

两种写法的区别

写法

终止时状态

适用场景

while left <= right

left > right（区间为空）

找 target，可能提前 return

while left < right

left == right（区间收敛到一个点）

找一定存在的值，收敛后就是答案

while left 小于等于 right

用于找 target 的标准二分：找到就提前 return mid，找不到返回 -1。

while left <= right:
    mid = (left + right) // 2
    if nums[mid] == target:
        return mid          # 提前退出
    elif target < nums[mid]:
        right = mid - 1
    else:
        left = mid + 1
return -1                    # 没找到

while left 小于 right

用于找一定存在的值（比如最小值）：不断缩小区间，最终 left == right 就是答案。

while left < right:
    mid = (left + right) // 2
    if nums[mid] <= nums[right]:
        right = mid         # mid 可能是答案，不能跳过
    else:
        left = mid + 1      # mid 肯定不是答案，可以跳过
return nums[left]            # left == right，就是最小值

关键点

  • right = mid（不是 mid - 1）：因为 mid 本身可能是答案
  • left = mid + 1：因为能确定 mid 不是答案
  • 这种搭配保证每轮区间严格缩小，不会死循环

二分法中 left right 的含义

通常是索引（指向数组位置），但也有例外：

  • 两个有序数组的中位数：left/right 表示数量（贡献几个元素到左半），所以 right = m（不是 m-1）

相关题目

  • 搜索旋转排序数组（第 33 题）— while left <= right，找 target
  • 寻找旋转排序数组中的最小值（第 153 题）— while left < right，收敛到最小值
  • 寻找两个正序数组的中位数（第 4 题）— while left <= right，但 left/right 是数量不是索引
