附录一 控制流结构 if elif 与 if if

核心原则 这一步要做几个动作

模式

结构

原因

二分 / 双指针

if/elif/else

每一步只走一个方向，缩小范围

DFS 递归

if + if（或 for 循环）

每个节点要探索所有合法分支

BFS 迭代

for 循环 + if 过滤

每个节点也要把所有合法邻居加入队列

总结

  • 逼近类（二分、双指针）：一步只走一条路 → if/elif/else
  • 搜索/遍历类（DFS、BFS）：一步要走多条路 → if+if 或 for 循环

为什么逼近类不能用 if if

while 循环里每轮做一个决策、移动一步，然后让下一轮循环自然处理后续。两个 if 连着写意味着一轮里做了两次决策，容易互相干扰（比如第一个 if 改了 left，第二个 if 基于改过的值又动了 right）。

DFS 的两个 if 本质是 for 循环

括号生成为例，两个 if 等价于遍历两个候选：

# 两个 if 写法
if opens < n:
    dfs(path + '(', opens + 1, closes)
if closes < opens:
    dfs(path + ')', opens, closes + 1)

# 等价的 for 循环写法
for c in ['(', ')']:
    if c == '(' and opens >= n: continue
    if c == ')' and closes >= opens: continue
    dfs(path + c, ...)

候选只有两个时 for 循环退化成两个 if，所以看起来不同，本质一样。

相关题目

  • 二分查找（搜索旋转排序数组）— if/elif 每轮只缩小一次区间
  • 括号生成（第 22 题）— if + if 探索所有合法分支
  • BFS 层序遍历 — for 循环遍历所有邻居
