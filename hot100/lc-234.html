第 24 题 回文链表

LeetCode 234 Palindrome Linked List

难度 简单 标签 链表 栈 递归 原题链接

题面

给你一个单链表的头节点 head ，请你判断该链表是否为回文链表。如果是，返回 true ；否则，返回 false 。

示例 1：

输入： head = [1,2,2,1]
输出： true

示例 2：

输入： head = [1,2]
输出： false

提示：

  • 链表中节点数目在范围 [1, 105] 内
  • 0 <= Node.val <= 9

进阶： 你能否用 O(n) 时间复杂度和 O(1) 空间复杂度解决此题？

思路

  • 三步走：找中点 → 反转后半段 → 逐个比较
  1. 快慢指针找中点：slow 走 1 步，fast 走 2 步，fast 到终点时 slow 在中间（偶数长度返回偏右的中点）
  2. 反转后半段链表：从中点开始反转
  3. 双指针比较：l 从头走，r 从反转后的后半段走，逐个比较值是否相等。用 while r 控制（后半段更短或等长）
  • 易错点：
  1. 嵌套函数不需要 `self` 参数：middle 和 rever 是定义在方法内部的嵌套函数，不是类方法。如果写了 self，调用 middle(head) 时 head 会被传给 self，真正的 head 参数缺失，报错 TypeError: missing 1 required positional argument
  2. 快慢指针的终止条件是 `while fast and fast.next`：两个条件缺一不可，分别处理偶数（fast 走到 None）和奇数（fast 走到最后一个节点）的情况

代码实现

class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        def middle(head):
            fast, slow = head, head
            while fast and fast.next:
                slow = slow.next
                fast = fast.next.next
            return slow

        def rever(head):
            pre, cur = None, head
            while cur:
                tmp = cur.next
                cur.next = pre
                pre = cur
                cur = tmp
            return pre

        mid_node = middle(head)
        head2 = rever(mid_node)

        l = head
        r = head2
        while r:
            if l.val != r.val:
                return False
            l = l.next
            r = r.next
        return True
  • 复杂度：时间 O(n)，空间 O(1)（只用了指针变量，原地反转）
