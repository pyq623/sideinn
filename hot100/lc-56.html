第 14 题 合并区间

LeetCode 56 Merge Intervals

难度 中等 标签 普通数组 数组 排序 原题链接

题面

以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [starti, endi] 。请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。

示例 1：

输入： intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释： 区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].

示例 2：

输入： intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释： 区间 [1,4] 和 [4,5] 可被视为重叠区间。

示例 3：

输入： intervals = [[4,7],[1,4]]
输出：[[1,7]]
解释： 区间 [1,4] 和 [4,7] 可被视为重叠区间。

提示：

  • 1 <= intervals.length <= 104
  • intervals[i].length == 2
  • 0 <= starti <= endi <= 104

思路

  • 关键第一步：按左端点排序。排序后，能合并的区间一定是相邻的，不会出现跳跃合并的情况
  • 排序后，遍历每个区间，只需要和 ans 中最后一个区间比较：
  • 如果当前区间的左端点 v[0] <= 上一个区间的右端点 ans[-1][1]，说明有重叠，合并：只需要更新右边界为两者的较大值（左边界不用动，因为排过序，当前左端点一定 >= 上一个左端点）
  • 否则没有重叠，当前区间作为新的独立区间加入 ans
  • 精妙之处：
  • 排序将问题简化为只和前一个比较，不需要和所有已有区间比较
  • 合并时只改右边界（max(ans[-1][1], v[1])），因为左边界在排序后已经保证有序
  • ans 始终维护着合并后的结果，每个区间只看一次，整体 O(N)
  • 易错点：第一次循环时 ans 为空，ans[-1] 会越界，需要先判断 ans 非空
  • 能不能按右端点排序？
  • 可以，但需要倒着遍历 intervals 数组
  • 如果按右端点排序后正着遍历，比如 [1,2], [4,5], [1,6] 这三个区间，正确答案应合并成 [1,6]，但正着遍历到 [4,5] 时，无法知道它能否和 [1,2] 彻底断开（后面还有 [1,6] 会把它们连起来）
  • 按左端点排序就不会有这个问题：左端点有序保证了能合并的区间一定相邻，遍历到当前区间时，只看前一个就够了

代码实现

class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort(key=lambda p: p[0])
        ans = []

        for v in intervals:
            if ans and v[0] <= ans[-1][1]:  # 新的value的左边比上一个的右边小，纳入范围
                ans[-1][1] = max(ans[-1][1], v[1])  # 只变化右边界
            else:  # 未能融入
                ans.append(v)
        return ans
  • 复杂度：时间 O(N log N)（排序），空间 O(N)（结果数组）
