第 02 题 字母异位词分组

LeetCode 49 Group Anagrams

难度 中等 标签 哈希 数组 哈希表 字符串 排序 原题链接

题面

给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

示例 1:

输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

输出:[["bat"],["nat","tan"],["ate","eat","tea"]]

解释：

  • 在 strs 中没有字符串可以通过重新排列来形成 "bat"。
  • 字符串 "nat" 和 "tan" 是字母异位词，因为它们可以重新排列以形成彼此。
  • 字符串 "ate" ，"eat" 和 "tea" 是字母异位词，因为它们可以重新排列以形成彼此。

示例 2:

输入: strs = [""]

输出:[[""]]

示例 3:

输入: strs = ["a"]

输出:[["a"]]

提示：

  • 1 <= strs.length <= 104
  • 0 <= strs[i].length <= 100
  • strs[i] 仅包含小写字母

思想：它这个题目说的字母异位词，其实就是统计每个string里的字母，字母出现的数量和类型一致的，就是同一个词。 根据此，将每个string排序后作为key。 注意这里要使用列表字典，所以普通的字典想要value作为列表会比较麻烦，直接使用defaultdict(list)比较方便。

解法

from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        str_dict = defaultdict(list)
        for s in strs:
            sorted_s = ''.join(sorted(s))
            str_dict[sorted_s].append(s)
        return list(str_dict.values())

语法要点

  • defaultdict(list)：key 不存在时自动创建空列表，免去 if key not in dict 的判断
  • sorted(s)：返回字符排序后的列表 ['a','e','t']，不修改原字符串
  • ''.join(...)：用空字符串将列表拼接回字符串，''.join(['a','e','t']) → "aet"
  • .values()：返回字典所有 value 的视图，需用 list() 转为列表返回
  • 注意 list（小写，内置类型）和 List（大写，typing 注解）的区别：defaultdict(List) 会报错
