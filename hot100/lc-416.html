第 89 题 分割等和子集

LeetCode 416 Partition Equal Subset Sum

难度 中等 标签 动态规划 数组 原题链接

题面

给你一个 只包含正整数 的 非空 数组 nums 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

示例 1：

输入： nums = [1,5,11,5]
输出： true
解释： 数组可以分割成 [1, 5, 5] 和 [11] 。

示例 2：

输入： nums = [1,2,3,5]
输出： false
解释： 数组不能分割成两个元素和相等的子集。

提示：

  • 1 <= nums.length <= 200
  • 1 <= nums[i] <= 100

思路

关键转化：把数组分成两个等和子集 = 从数组中选一些数，使它们的和恰好等于 sum/2。

dp[j] 表示：能不能从数组中选一些数，使得和恰好等于 j。

递推：dp[j] = dp[j] or dp[j - num]

  • dp[j]：不选当前 num，之前就能凑出 j
  • dp[j - num]：选当前 num，之前能凑出 j-num

为什么要从大到小遍历 j 非常重要

从大到小 = 每个数只用一次（01背包），从小到大 = 每个数可以无限用（完全背包）。

用例子看 nums = [1, 2, 5], target = 4：

从小到大（错误）：

num = 1:
  j=1: dp[1] = dp[1] or dp[0] = True   ← 用了一次 1
  j=2: dp[2] = dp[2] or dp[1] = True   ← dp[1] 刚更新过！等于用了两次 1
  j=3: dp[3] = dp[3] or dp[2] = True   ← 等于用了三次 1

1 只有一个，但从小到大让它被"重复利用"了。

从大到小（正确）：

num = 1:
  j=4: dp[4] = dp[4] or dp[3] = False  ← dp[3] 还是旧值 False
  j=3: dp[3] = dp[3] or dp[2] = False  ← dp[2] 还是旧值 False
  j=2: dp[2] = dp[2] or dp[1] = False  ← dp[1] 还是旧值 False
  j=1: dp[1] = dp[1] or dp[0] = True   ← 最后才更新

从大到小保证了：算 dp[j] 时，dp[j-num] 读到的是上一轮的旧值，不会被本轮污染。每个数只用一次。

range target num 1 1 的含义

range(起点, 终点, 步长)
range(target, num - 1, -1) → 从 target 倒着数到 num（含 num）

为什么最小到 num？因为 dp[j - num] 需要 j >= num，比 num 小的 j 没法选这个数，不用更新。

代码实现

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        n = len(nums)
        sum_n = sum(nums)
        if sum_n % 2 == 1:
            return False
        target = sum_n // 2
        dp = [False] * (target + 1)
        dp[0] = True
        for num in nums:
            for j in range(target, num - 1, -1):  # 从大到小
                dp[j] = dp[j] or dp[j - num]
        return dp[target]
  • 易错点：
  1. 内层循环必须从大到小：从小到大会让同一个数被重复使用（变成完全背包）。01背包 = 从大到小，完全背包 = 从小到大
  2. dp 长度是 `target + 1` 不是 `n + 1`：dp[j] 表示能否凑出和为 j，j 的范围是 0~target
  3. 总和为奇数直接返回 False：奇数不可能平分成两个相等的整数
  4. `dp[0] = True`：和为 0 什么都不选就行，是合法的起点
  • 复杂度：时间 O(n × target)，空间 O(target)
