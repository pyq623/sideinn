第 75 题 前 K 个高频元素

LeetCode 347 Top K Frequent Elements

难度 中等 标签 堆 数组 哈希表 分治 桶排序 计数 快速选择 排序 堆（优先队列） 原题链接

题面

给你一个整数数组 nums 和一个整数 k ，请你返回其中出现频率前 k 高的元素。你可以按 任意顺序 返回答案。

示例 1：

输入： nums = [1,1,1,2,2,3], k = 2

输出：[1,2]

示例 2：

输入： nums = [1], k = 1

输出：[1]

示例 3：

输入： nums = [1,2,1,2,1,2,3,1,3,2], k = 2

输出：[1,2]

提示：

  • 1 <= nums.length <= 105
  • -104 <= nums[i] <= 104
  • k 的取值范围是 [1, 数组中不相同的元素的个数]
  • 题目数据保证答案唯一，换句话说，数组中前 k 个高频元素的集合是唯一的

进阶： 你所设计算法的时间复杂度 必须 优于 O(n log n) ，其中 n 是数组大小

核心区别在 return：

  • 上一题返回一个数，递归到底拿到就行，每层直接透传
  • 这一题返回一组数，递归 small 时 big + equal 已经确定是答案的一部分，不能丢，必须拼接起来

三个分支的返回逻辑

big:   [频率 > pivot]
equal: [频率 == pivot]
small: [频率 < pivot]

从高频到低频排列：big + equal + small

else（落在 equal）

elif 递归 small

big + equal 不够 k 个

解法一 小顶堆 O n log k

和上一题一样，维护一个大小为 k 的小顶堆。区别是上一题存元素值，这一题存 (频率, 元素) —— heapq 按元组第一个值排序，所以频率放前面。

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        from collections import Counter
        import heapq
        cnt = Counter(nums)
        heap = []
        for num, freq in cnt.items():
            heapq.heappush(heap, (freq, num))
            if len(heap) > k:
                heapq.heappop(heap)
        return [num for freq, num in heap]

堆始终只保留频率最高的 k 个，每次弹出的是频率最小的那个。

解法二 快速选择 O n

代码实现

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        from collections import Counter
        import random
        cnt = Counter(nums)
        items = list(cnt.items())
        def quickselect(items, k):
            small, equal, big = [], [], []
            pivot = random.choice(items)[1] # 随机选一个的频率
            for num, freq in items:
                if freq < pivot:
                    small.append((num, freq))
                elif freq > pivot:
                    big.append((num, freq))
                else:
                    equal.append((num, freq))
            if k <= len(big):
                rest = quickselect(big, k)
                return rest
            elif len(items) - len(small) < k:
                rest = quickselect(small, k - (len(items) - len(small)))
                return [n for n, f in big + equal] + rest
            else:
                result = [n for n, f in big + equal]
                return result
        result = quickselect(items, k)
        return result
  • 易错点：
  1. `random.choice(items)[1]`，不是 `random.randint(items)`：choice 从列表随机选一个元素，选出来是 (num, freq) 元组，取 [1] 拿频率作为 pivot
  2. 递归里全部用参数 `k`，不能用外层的 `k`：和上一题一样的坑，递归时 k 会调整，混用外层变量会导致递归进空列表报错
  3. 递归 small 时不能只返回递归结果：big + equal 里的元素已经确认是前 k 高频的一部分，必须 [n for n, f in big + equal] + rest 拼起来。上一题不需要是因为只返回一个数
  4. else 分支要返回 `big + equal`，不能只返回 `equal`：big 里的元素频率比 equal 更高，当然也是前 k 高频的一部分
  5. `len(items)` 不能写成 `len(nums)`：递归时 items 是当前层的列表，nums 是最外层的原始数组，长度完全不同。用 len(nums) 算 k 的偏移量会算错，导致递归进空列表报 IndexError: Cannot choose from an empty sequence
  6. `for num in cnt` 只能拿到 key：要同时拿 key 和 value，用 cnt.items()，或者 cnt[num] 取 value
  • 复杂度：平均 O(n)，空间 O(n)（Counter + 三个列表），和上一题相同
