附录二 可变与不可变类型的回溯

核心区别 需不需要手动回溯

类型

例子

回溯方式

需要 path[:] 收集？

不可变类型

str, int, tuple

天然回溯（path + '(' 创建新对象）

不需要（直接 append）

可变类型

list, dict

必须手动回溯（path.pop()）

需要 `path[:]`（深拷贝）

不可变类型 str int

# 字符串天然回溯，不需要 pop
def dfs(path, opens, closes):
    if len(path) == 2 * n:
        self.res.append(path)    # 直接 append，不需要 [:]
        return
    if opens < n:
        dfs(path + '(', opens + 1, closes)  # path + '(' 创建新字符串
    # 上层的 path 没变，不需要回溯

可变类型 list

# 列表必须手动回溯
def dfs(path, start):
    if condition:
        self.res.append(path[:])  # 必须 path[:]，否则所有结果指向同一个列表
        return
    for i in range(start, n):
        path.append(nums[i])      # 做选择
        dfs(path, i + 1)
        path.pop()                # 撤销选择（手动回溯）

为什么 list 需要 path

path 是一个引用。如果直接 self.res.append(path)，res 里存的是同一个列表的引用。后续 path.pop() 和 path.append() 会改变这个列表，导致 res 里所有"结果"跟着变。

path[:] 创建一个快照副本，和原 path 脱钩。

dict 同理

如果用 dict 记录状态，收集结果时也要 dict.copy() 或 dict(path)。
