第 71 题 字符串解码

LeetCode 394 Decode String

难度 中等 标签 栈 递归 字符串 原题链接

题面

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: k[encodedstring]，表示其中方括号内部的 encodedstring 正好重复 k 次。注意 k 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 k ，例如不会出现像 3a 或 2[4] 的输入。

测试用例保证输出的长度不会超过 105。

示例 1：

输入： s = "3[a]2[bc]"
输出： "aaabcbc"

示例 2：

输入： s = "3[a2[c]]"
输出： "accaccacc"

示例 3：

输入： s = "2[abc]3[cd]ef"
输出： "abcabccdcdcdef"

示例 4：

输入： s = "abc3[cd]xyz"
输出： "abccdcdcdxyz"

提示：

  • 1 <= s.length <= 30
  • s 由小写英文字母、数字和方括号 '[]' 组成
  • s 保证是一个 有效 的输入。
  • s 中所有整数的取值范围为 [1, 300]

思路

  • 用栈来处理嵌套结构：遇到 [ 就"存档"压栈，遇到 ] 就"读档"弹出拼接
  • 栈里存的是 (之前的字符串, 重复次数) 这个配对，两个信息缺一不可

四种字符的处理

字符

动作

数字

cur_num = cur_num * 10 + int(c)（累积，处理多位数如 12）

[

把 (cur_str, cur_num) 压入栈，然后重置两者

字母

cur_str += c

]

弹出 (prev_str, num)，拼接 cur_str = prev_str + num * cur_str

为什么栈里存 curstr curnum 配对

遇到 [ 时需要"暂停"两样东西：之前已经拼好的字符串（等内层解析完要接在后面）和当前的重复次数（等内层解析完要用它重复）。这两个信息必须配对保存，遇到 ] 时一起取出才能正确拼接。

用 3 a2 c 走一遍

字符  动作                          栈                 cur_str    cur_num
 3   累积数字                       []                 ""         3
 [   压栈("",3)，重置               [("",3)]           ""         0
 a   拼到 cur_str                   [("",3)]           "a"        0
 2   累积数字                       [("",3)]           "a"        2
 [   压栈("a",2)，重置              [("",3),("a",2)]   ""         0
 c   拼到 cur_str                   [("",3),("a",2)]   "c"        0
 ]   弹出("a",2) → "a"+"c"*2       [("",3)]           "acc"      0
 ]   弹出("",3) → ""+"acc"*3       []                 "accaccacc" 0

结果："accaccacc" ✓

代码实现

class Solution:
    def decodeString(self, s: str) -> str:
        stack = []
        cur_num = 0
        cur_str = ""
        for i in s:
            if i.isdigit():
                cur_num = cur_num * 10 + int(i)
            elif i == '[':
                stack.append((cur_str, cur_num))
                cur_num = 0
                cur_str = ""
            elif i.isalpha():
                cur_str += i
            elif i == ']':
                (prev_str, num) = stack.pop()
                cur_str = prev_str + num * cur_str
        return cur_str
  • 写代码技巧：这道题一定要对着题例（如 3[a2[c]]）一步步模拟着写代码，直接凭空写很容易搞混存档/读档的逻辑
  • 易错点：
  1. 多位数处理 `cur_num = cur_num * 10 + int(i)`：数字可能不是个位数（如 12[a]），不能直接 cur_num = int(i)
  2. 遇到 `[` 后必须重置 `cur_str` 和 `cur_num`：不重置的话内层结果会混入外层的状态
  3. 拼接顺序是 `prev_str + num * cur_str`：是"之前的字符串 + 重复后的当前字符串"，不是反过来
  4. 栈里存配对 `(cur_str, cur_num)`：只存一个会丢失另一个信息，导致无法正确拼接
  5. `isdigit()` 和 `isalpha()` 没有下划线：不是 is_digit() / is_alpha()
  • 复杂度：时间 O(n)（n 为解码后字符串长度），空间 O(n)（栈深度）
