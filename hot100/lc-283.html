第 04 题 移动零

LeetCode 283 Move Zeroes

难度 简单 标签 双指针 数组 原题链接

题面

给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

请注意 ，必须在不复制数组的情况下原地对数组进行操作。

示例 1:

输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]

示例 2:

输入: nums = [0]
输出: [0]

提示 :

  • 1 <= nums.length <= 10^4
  • -2^31 <= nums[i] <= 2^31 - 1

进阶： 你能尽量减少完成的操作次数吗？

思想：原地操作，就是直接对nums进行修改。

解法

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        stacksize = 0
        for x in nums:
            if x != 0:
                nums[stacksize] = x
                stacksize = stacksize + 1
        for i in range(stacksize, len(nums)):
            nums[i] = 0
        return nums

解法二 交换法

思想：i0 始终指向"第一个 0 的位置"。i 向前扫描，遇到非零就和 i0 交换——相当于把非零元素换到前面，0 被换到后面。如果前面没有 0，i 和 i0 同步前进，swap 是自交换（no-op）；一旦遇到 0，i0 停住、i 继续走，之后的 swap 才真正生效。这样第一次i遇到0，就会和i0拉开一点差距，i0指向的就是0，i如果后面继续非0，就一边交换，一边继续前进；如果是0，则i0不前进，i前进。之后如果只需一次遍历，不需要第二轮填零。

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        i0 = 0
        for i in range(len(nums)):
            if nums[i] != 0:
                nums[i0], nums[i] = nums[i], nums[i0]
                i0 = i0 + 1
        return nums

语法要点

  • range(stacksize, len(nums))：从 stacksize 到 len(nums)-1，左闭右开
  • 原地修改：题目要求不返回新数组，直接修改 nums（实际上 return nums 可省略）
  • nums[i0], nums[i] = nums[i], nums[i0]：Python 同时赋值语法，一行完成交换，不需要临时变量
  • stacksize / i0 都充当慢指针，记录下一个非零元素应放的位置
