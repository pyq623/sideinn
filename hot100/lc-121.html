第 77 题 买卖股票的最佳时机

LeetCode 121 Best Time to Buy and Sell Stock

难度 简单 标签 贪心算法 数组 动态规划 原题链接

题面

给定一个数组 prices ，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0 。

示例 1：

输入：[7,1,5,3,6,4]
输出： 5
解释： 在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

示例 2：

输入： prices = [7,6,4,3,1]
输出： 0
解释： 在这种情况下, 没有交易完成, 所以最大利润为 0。

提示：

  • 1 <= prices.length <= 105
  • 0 <= prices[i] <= 104

思路

暴力双循环 O(n²) 会超时。关键观察：对于每一天，想知道"今天卖出能赚多少"，只需要知道之前的历史最低价。

所以只需一层循环，遍历过程中维护两个变量：

  • low：到目前为止的历史最低价
  • profit：全局最大利润
[7, 1, 5, 3, 6, 4]
 7  1  1  1  1  1   ← low
 0  0  4  2  5  3   ← p - low
                ↑ 最大利润 = 5

每天做两件事：更新历史最低价，算今天卖出的利润。

代码实现

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        profit = 0
        low = inf
        for p in prices:
            low = min(low, p)
            profit = max(profit, p - low)
        return profit
  • 易错点：
  1. `low` 初始值用 `inf`：保证第一天一定能更新 low。用 0 的话永远不会被更新
  2. 先更新 low 再算利润：顺序不能反，因为今天的价格既可能是新低价，也可能是卖出价（当天买当天卖利润为 0，不影响结果）
  3. 不需要双指针：虽然直觉是"找最低点和最高点的差"，但最高点必须在最低点之后。维护历史最低价天然保证了时间顺序
  • 复杂度：时间 O(n)，空间 O(1)
