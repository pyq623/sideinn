第 91 题 不同路径

LeetCode 62 Unique Paths

难度 中等 标签 多维动态规划 数学 动态规划 组合数学 原题链接

题面

一个机器人位于一个 m x n 网格的左上角 （起始点在下图中标记为 "Start" ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 "Finish" ）。

问总共有多少条不同的路径？

示例 1：

输入： m = 3, n = 7
输出： 28

示例 2：

输入： m = 3, n = 2
输出： 3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下

示例 3：

输入： m = 7, n = 3
输出： 28

示例 4：

输入： m = 3, n = 3
输出： 6

提示：

  • 1 <= m, n <= 100
  题目数据保证答案小于等于 `2 * 10^9`

思路

含义

到第i阶 = 从i-1来 + 从i-2来

到(i,j) = 从上面来 + 从左边来

求什么

方案数（加法）

方案数（加法）

到达 (i, j) 只有两种方式：从上面 (i-1, j) 往下走一步，或从左边 (i, j-1) 往右走一步。

边界条件：

  • 第一行 dp[0][j] = 1：只能一直向右走，只有 1 种走法
  • 第一列 dp[i][0] = 1：只能一直向下走，只有 1 种走法
m=3, n=3 的网格：

dp:
[1, 1, 1]
[1, 2, 3]
[1, 3, 6]  ← 答案是 dp[2][2] = 6

代码实现

class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [[0] * n for _ in range(m)]
        for i in range(m):
            dp[i][0] = 1
        for j in range(n):
            dp[0][j] = 1

        for i in range(1, m):
            for j in range(1, n):
                dp[i][j] = dp[i-1][j] + dp[i][j-1]
        return dp[m-1][n-1]
  • 易错点：
  1. 边界初始化为 1 不是 0：第一行和第一列只有唯一走法（一直右/一直下），不初始化的话后续递推全是 0
  2. 循环从 1 开始：range(1, m) 和 range(1, n)，因为第 0 行和第 0 列已经初始化过了
  3. 返回 `dp[m-1][n-1]`：终点固定在右下角，不是 max(dp)
  • 复杂度：时间 O(m × n)，空间 O(m × n)
