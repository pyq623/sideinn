第 86 题 单词拆分

LeetCode 139 Word Break

难度 中等 标签 动态规划 字典树 记忆化 数组 哈希表 字符串 原题链接

题面

给你一个字符串 s 和一个字符串列表 wordDict 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 s 则返回 true。

注意： 不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

示例 1：

输入: s = "leetcode", wordDict = ["leet", "code"]
输出: true
解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。

示例 2：

输入: s = "applepenapple", wordDict = ["apple", "pen"]
输出: true
解释: 返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
     注意，你可以重复使用字典中的单词。

示例 3：

输入: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出: false

提示：

  • 1 <= s.length <= 300
  • 1 <= wordDict.length <= 1000
  • 1 <= wordDict[i].length <= 20
  • s 和 wordDict[i] 仅由小写英文字母组成
  • wordDict 中的所有字符串 互不相同

dp[i] 表示 s[0:i] 能否被字典里的单词拼成。对每个位置 i，枚举所有切割点 j：

如果 dp[j] == True 且 s[j:i] 在字典里 → dp[i] = True

意思是：前 j 个字符能拼出来，且 s[j:i] 这一段在字典里，那前 i 个字符就能拼出来。

s = "leetcode", words = {"leet", "code"}

dp[0] = True（空串）
i=4: j=0, dp[0]=True, s[0:4]="leet" in words → dp[4]=True
i=8: j=4, dp[4]=True, s[4:8]="code" in words → dp[8]=True

return dp[8] = True

为什么 i 是外层 j 是内层 很重要

i 是终点（从左到右推进），j 是切割点（在 i 内部枚举）。

j 作为起点，对于每个固定的 i，要把所有可能的 j 都试一遍，所以 j 是内层要先被循环完。而 i 是终点，从小到大逐步推进，作为外层。

算 dp[i] 时需要 dp[j]（j < i）已经确定。i 从小到大做外层，就保证了算 dp[i] 时所有 dp[j] 都已经算好了：

i=1: dp[0] 已知 → 算 dp[1]
i=2: dp[0], dp[1] 已知 → 算 dp[2]
i=4: dp[0]~dp[3] 已知 → 算 dp[4]
i=8: dp[0]~dp[7] 已知 → 算 dp[8]

如果反过来让 j 做外层（先固定起点），算 dp[i] 时 dp[j] 可能还没算出来，就会漏掉合法的拆分。

规律：DP 的递推方向一定是"从已知推未知"。dp[i] 依赖 dp[j]（j < i），所以 i 从小到大做外层。

代码实现

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n = len(s)
        set_w = set(wordDict)
        dp = [False] * (n + 1)
        dp[0] = True

        for i in range(1, n + 1):
            for j in range(i):
                if dp[j] and s[j:i] in set_w:
                    dp[i] = True
        return dp[n]
  • 易错点：
  1. wordDict 要转成 set：s[j:i] in list 是 O(n)，in set 是 O(1)，不转可能超时
  2. `dp[0] = True`：空串是 True，表示"什么都不用拼"这个起点存在。和前面题目的 dp[0] = 0 是一样的意义
  3. i 做外层不能反过来：dp[i] 依赖 dp[j]（j < i），必须先算小的再算大的
  4. 找到一种拆法就够了：可以加 break 提前退出内层循环，但不加也能通过
  • 复杂度：时间 O(n²)（双层循环，s[j:i] 切片也是 O(n)，总共 O(n³)），空间 O(n)
