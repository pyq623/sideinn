第 61 题 分割回文串

LeetCode 131 Palindrome Partitioning

难度 中等 标签 回溯 字符串 动态规划 原题链接

题面

给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是 回文串 。返回 s 所有可能的分割方案。

示例 1：

输入： s = "aab"
输出：[["a","a","b"],["aa","b"]]

示例 2：

输入： s = "a"
输出：[["a"]]

提示：

  • 1 <= s.length <= 16
  • s 仅由小写英文字母组成

思路

  • 本质是子集（第 56 题）的变体：子集是从数组里选元素，本题是从字符串里选切割位置
  • 回文判断：s == s[::-1]（[::-1] 是 Python 切片反转，正着反着一样就是回文）

和子集的对比

# 子集：每次选一个元素加入 path
def dfs(start, path):
    self.res.append(path[:])          # 每个节点都收集
    for i in range(start, n):
        path.append(nums[i])          # 选一个元素
        dfs(i + 1, path)
        path.pop()

# 分割回文串：每次选一段子串加入 path
def dfs(start, path):
    if start == n:                     # 切完了整个字符串才收集
        self.res.append(path[:])
        return
    for i in range(start, n):
        sub_s = s[start:i+1]          # 选一段子串（从 start 切到 i）
        if sub_s == sub_s[::-1]:      # 是回文才选（剪枝）
            path.append(sub_s)
            dfs(i + 1, path)
            path.pop()

子集（第 56 题）

分割回文串（本题）

选什么

一个元素 nums[i]

一段子串 s[start:i+1]

收集时机

每个节点都收集

start == n（切完整个字符串）才收集

剪枝

无

不是回文就跳过

start 含义

从第几个元素开始选

从字符串第几个位置开始切

i 含义

选了哪个元素

这一刀切到哪里

用 "aab" 走一遍

dfs(0, [])
  i=0: sub="a" ✓回文 → dfs(1, ["a"])
    i=1: sub="a" ✓ → dfs(2, ["a","a"])
      i=2: sub="b" ✓ → dfs(3, ["a","a","b"])
        start==3，收集 ["a","a","b"] ✓
    i=2: sub="ab" ✗不是回文，跳过
  i=1: sub="aa" ✓回文 → dfs(2, ["aa"])
    i=2: sub="b" ✓ → dfs(3, ["aa","b"])
      start==3，收集 ["aa","b"] ✓
  i=2: sub="aab" ✗不是回文，跳过

结果：[["a","a","b"], ["aa","b"]]  ✓

为什么收集条件从"每个节点"变成了 start n

子集允许任意长度（包括空集），所以每个节点都收集。分割要求所有子串拼起来等于原字符串，只有切完了（start 走到末尾）才是一个完整的分割方案。

代码实现

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        self.res = []
        n = len(s)
        def dfs(start, path):
            if start == n:
                self.res.append(path[:])
                return
            for i in range(start, n):
                sub_s = s[start:i+1]
                if sub_s == sub_s[::-1]:
                    path.append(sub_s)
                    dfs(i + 1, path)
                    path.pop()
        path = []
        dfs(0, path)
        return self.res
  • 易错点：
  1. `s[start:i+1]` 不是 `s[start:i]`：Python 切片是左闭右开，s[0:1] 才是第一个字符
  2. `start == n` 才收集：不是每个节点都收集，必须切完整个字符串才算一个合法方案
  3. `self.res.append(path[:])` 不是 `append(path)`：list 可变类型，不复制会被后续 pop 改掉
  4. 回文判断是 `sub_s == sub_s[::-1]`：[::-1] 是切片反转（步长 -1，从后往前取），正着反着一样就是回文
  • 复杂度：时间 O(n × 2^n)（最多 2^n-1 种切法，每种检查回文 O(n)），空间 O(n)（递归深度）
