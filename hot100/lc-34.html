第 65 题 在排序数组中查找元素的第一个和最后一个位置

LeetCode 34 Find First and Last Position of Element in Sorted Array

难度 中等 标签 二分查找 数组 原题链接

题面

给你一个按照非递减顺序排列的整数数组 nums，和一个目标值 target。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 target，返回 [-1, -1]。

你必须设计并实现时间复杂度为 O(log n) 的算法解决此问题。

示例 1：

输入： nums = [5,7,7,8,8,10], target = 8
输出：[3,4]

示例 2：

输入： nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]

示例 3：

输入： nums = [], target = 0
输出：[-1,-1]

提示：

  • 0 <= nums.length <= 105
  • -109 <= nums[i] <= 109
  • nums 是一个非递减数组
  • -109 <= target <= 109

思路

  • 和第 63 题（搜索插入位置）同一个模板，做两次二分：一次找左边界，一次找右边界
  • 区别：找到 target 时不急着返回，继续往一边搜

和第 63 题的对比

# 第 63 题：找到就返回
if nums[mid] == target:
    return mid

# 找左边界：找到了还往左搜
if nums[mid] == target:
    right = mid - 1         # 继续往左，看有没有更左的 target

# 找右边界：找到了还往右搜
if nums[mid] == target:
    left = mid + 1          # 继续往右，看有没有更右的 target

用例子走一遍 nums 5 7 7 8 8 10 target 8

找左边界（else: right = mid - 1）：
  left=0, right=5, mid=2 → 7 < 8  → left=3
  left=3, right=5, mid=4 → 8 == 8 → right=3（继续往左！）
  left=3, right=3, mid=3 → 8 == 8 → right=2（继续往左！）
  left=3 > right=2 → 结束，left_bound = left = 3 ✓

找右边界（else: left = mid + 1）：
  left=0, right=5, mid=2 → 7 < 8  → left=3
  left=3, right=5, mid=4 → 8 == 8 → left=5（继续往右！）
  left=5, right=5, mid=5 → 10 > 8 → right=4
  left=5 > right=4 → 结束，right_bound = right = 4 ✓

为什么推的是一个指针 答案却是另一个

以找右边界为例：else: left = mid + 1，left 被不断往右推，最终推过头（推到了 target 右边），而 right 被 mid - 1 拉回来，刚好停在最后一个 target 上。

else 里推谁

推过头的是谁

答案是谁

找左边界

right = mid - 1

right（推到 target 左边去了）

left

找右边界

left = mid + 1

left（推到 target 右边去了）

right

你推的那个指针会过头，答案是另一个。

target 不存在时

两次二分都不会进入 else 分支，经历的变化完全一样。循环条件是 while left <= right，退出时必然 left > right，即 left = right + 1。两次结果一样，所以 left_bound = left，right_bound = right = left - 1，天然 left_bound > right_bound，返回 [-1, -1]。

代码实现

class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        # 找左边界
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] < target:
                left = mid + 1
            elif nums[mid] > target:
                right = mid - 1
            else:
                right = mid - 1
        left_bound = left

        # 找右边界
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] < target:
                left = mid + 1
            elif nums[mid] > target:
                right = mid - 1
            else:
                left = mid + 1
        right_bound = right
        if left_bound > right_bound:
            return [-1, -1]
        return [left_bound, right_bound]
  • 易错点：
  1. 找到 target 不能直接返回：要继续搜，找到最左/最右的那个
  2. `left_bound = left`，`right_bound = right`：推的那个指针会过头，答案是另一个
  3. `left_bound > right_bound` 时返回 `[-1, -1]`：target 不存在时两次二分结果一样，天然 left > right
  4. 两次二分要分别重置 `left, right`：第一次二分后 left/right 已经变了
  • 复杂度：时间 O(log n)（两次二分），空间 O(1)
