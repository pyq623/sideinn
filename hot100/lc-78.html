第 56 题 子集

LeetCode 78 Subsets

难度 中等 标签 回溯 位运算 数组 原题链接

题面

给你一个整数数组 nums ，数组中的元素 互不相同 。返回该数组所有可能的子集（幂集）。

解集 不能 包含重复的子集。你可以按 任意顺序 返回解集。

示例 1：

输入： nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

示例 2：

输入： nums = [0]
输出：[[],[0]]

提示：

  • 1 <= nums.length <= 10
  • -10 <= nums[i] <= 10
  • nums 中的所有元素 互不相同

思路

  • 和上一题（46. 全排列）是同一个回溯框架，只有两个改动

和全排列的对比

# 全排列：每层从头遍历，跳过已用的
def dfs(path):
    if len(path) == len(nums):     # 选满了才收集
        self.res.append(path[:])
        return
    for i in nums:                 # 从头遍历所有数
        if i in path:              # 跳过已用过的
            continue
        path.append(i)
        dfs(path)
        path.pop()

# 子集：每层只往后选，不回头
def dfs(start, path):
    self.res.append(path[:])       # 每个节点都收集（包括空集）
    for i in range(start, n):      # 只往后选
        path.append(nums[i])
        dfs(i + 1, path)           # 下一层从 i+1 开始
        path.pop()

全排列（第 55 题）

子集（本题）

for 循环范围

for i in nums + if i in path

for i in range(start, n)

收集答案时机

len(path) == len(nums) 时

每次进入 dfs 都收集

递归参数

dfs(path)

dfs(i + 1, path)

为什么

排列要选满，[1,2] 和 [2,1] 算不同

子集不用选满，[1,2] 和 [2,1] 算相同

两个改动的原因

1. `range(start, n)` 而不是从头遍历

子集里 [1,2] 和 [2,1] 是同一个，所以不能回头选。start 保证只往后选，天然避免重复，不需要额外判断 if path in self.res。

2. 每次进入 dfs 就收集，不需要 if 判断

子集的长度可以是 0、1、2…… 任意长度，所以每个节点（包括空集）都是合法答案。

用 1 2 3 走一遍

dfs(0, []) → 收集 []
  i=0: dfs(1, [1]) → 收集 [1]
    i=1: dfs(2, [1,2]) → 收集 [1,2]
      i=2: dfs(3, [1,2,3]) → 收集 [1,2,3]，for 范围空，返回
    i=2: dfs(3, [1,3]) → 收集 [1,3]，返回
  i=1: dfs(2, [2]) → 收集 [2]
    i=2: dfs(3, [2,3]) → 收集 [2,3]，返回
  i=2: dfs(3, [3]) → 收集 [3]，返回

结果：[[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]  ✅

因为只往后选（start），永远不会出现 [2,1] 这种回头的情况，天然不重复。

代码实现

class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        self.res = []
        n = len(nums)
        def dfs(start, path):
            self.res.append(path[:])
            for i in range(start, n):
                path.append(nums[i])
                dfs(i + 1, path)
                path.pop()
        path = []
        dfs(0, path)
        return self.res
  • 易错点：
  1. 递归传 `i + 1` 不是 `start`：传 start 的话每层都从同一个位置开始，会重复选同一个元素
  2. `self.res.append(path[:])` 在 for 循环之前：这样空集也能被收集到。如果放在 for 里面就漏掉了空集
  3. `path[:]` 不是 `path`：和全排列一样，不复制的话后续 pop 会改掉
  4. 不需要终止条件：当 start == n 时，range(start, n) 为空，for 循环不执行，自然返回
  • 复杂度：时间 O(n × 2^n)（2^n 个子集，每个复制 O(n)），空间 O(n)（递归深度）
