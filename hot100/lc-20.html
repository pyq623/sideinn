第 69 题 有效的括号

LeetCode 20 Valid Parentheses

难度 简单 标签 栈 字符串 原题链接

题面

给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。

有效字符串需满足：

  1. 左括号必须用相同类型的右括号闭合。
  2. 左括号必须以正确的顺序闭合。
  3. 每个右括号都有一个对应的相同类型的左括号。

示例 1：

输入： s = "()"

输出： true

示例 2：

输入： s = "()[]{}"

输出： true

示例 3：

输入： s = "(]"

输出： false

示例 4：

输入： s = "([])"

输出： true

示例 5：

输入： s = "([)]"

输出： false

提示：

  • 1 <= s.length <= 104
  • s 仅由括号 '()[]{}' 组成

思路

控制流结构总结 if elif 与 if if

模式

结构

原因

二分 / 双指针

if/elif/else

每一步只走一个方向，缩小范围

DFS 递归

if + if（或 for 循环）

每个节点要探索所有合法分支

BFS 迭代

for 循环 + if 过滤

每个节点也要把所有合法邻居加入队列

  • 搜索/遍历类（DFS、BFS）：一步要走多条路 → if+if 或 for 循环
  • 逼近类（二分、双指针）：一步只走一条路 → if/elif/else

栈解法思路

遇到左括号就入栈，遇到右括号就检查栈顶是否匹配：

  1. 遇到 (、{、[ → 压入栈
  2. 遇到 )、}、] → 看栈顶是不是对应的左括号
  • 是 → 弹出栈顶（匹配成功）
  • 不是（或栈为空）→ 直接返回 False
  1. 遍历完后，栈为空 → True，否则 False

易错点

  • 栈为空时 pop 会报错，需要先检查 not stack
  • 遍历完后要检查栈是否为空（处理左括号多余的情况，如 "(((")

代码实现

class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        hash_map = {')':'(', ']': '[', '}': '{'}
        for i in s:
            if i not in hash_map:
                # 是左括号，入栈
                stack.append(i)
            else:
                if not stack or stack.pop() != hash_map[i]:
                    # 先判断栈是否空，不然pop会报错
                    return False
        if not stack:
            # 如果只入栈了左括号，则最后不空就是错
            return True
        else:
            return False
