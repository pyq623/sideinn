第 87 题 最长递增子序列

LeetCode 300 Longest Increasing Subsequence

难度 中等 标签 动态规划 数组 二分查找 原题链接

题面

给你一个整数数组 nums ，找到其中最长严格递增子序列的长度。

子序列 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，[3,6,2,7] 是数组 [0,3,1,6,2,2,7] 的子序列。

示例 1：

输入： nums = [10,9,2,5,3,7,101,18]
输出： 4
解释： 最长递增子序列是 [2,3,7,101]，因此长度为 4 。

示例 2：

输入： nums = [0,1,0,3,2,3]
输出： 4

示例 3：

输入： nums = [7,7,7,7,7,7,7]
输出： 1

提示：

  • 1 <= nums.length <= 2500
  • -104 <= nums[i] <= 104

进阶：

  • 你能将算法的时间复杂度降低到 O(n log(n)) 吗?

思路

和单词拆分结构一模一样：外层 i 做终点，内层 j 枚举所有 j < i。

单词拆分

最长递增子序列

外层 i

终点，从左到右推

终点，从左到右推

内层 j

枚举所有切割点 j < i

枚举所有前面的 j < i

判断条件

dp[j]==True 且 s[j:i] in words

nums[i] > nums[j]

递推

dp[i] = True（or）

dp[i] = max(dp[i], dp[j]+1)

dp[i] 表示以 nums[i] 结尾的最长递增子序列长度。对每个 i，看前面所有比它小的 j，取最长的 +1：

nums = [10, 9, 2, 5, 3, 7, 101, 18]
dp   = [ 1, 1, 1, 2, 2, 3,   4,  4]

最长 = max(dp) = 4，对应子序列 [2, 3, 7, 101]

为什么答案是 max dp 不是 dp n 1

和前几题的区别：

  • 爬楼梯 / 零钱兑换：终点固定（一定走到第 n 阶 / 凑出 amount），答案就是 dp[n]
  • 最长递增子序列：最长的子序列可能在任何位置结尾，所以答案是 max(dp)

为什么不能只看相邻元素 nums i 大于 nums i 1

这题求的是子序列（可以不连续），不是子数组（必须连续）。只看相邻的话：

nums = [10, 9, 2, 5, 3, 7, 101, 18]
只看相邻只能找到连续递增段，找不到 [2, 3, 7, 101] 这种跳着选的

代码实现

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [0] * (n + 1)

        for i in range(n):
            dp[i] = 1
            for j in range(i):
                if nums[i] > nums[j]:
                    dp[i] = max(dp[i], dp[j] + 1)
        return max(dp)
  • 易错点：
  1. `dp[i] = max(dp[i], dp[j]+1)` 必须取 max：直接 dp[i] = dp[j]+1 会被后面更小的值覆盖掉之前更优的结果
  2. 不需要 else 分支：nums[i] <= nums[j] 时，j 接不到 i 前面，直接跳过。不能写 dp[i] = max(dp[i], dp[j])，因为 dp[i] 的含义是以 nums[i] 结尾，和 dp[j] 无关
  3. 返回 `max(dp)` 不是 `dp[n-1]`：最长子序列不一定以最后一个元素结尾
  4. `dp[i] = 1` 初始化：每个元素自身至少构成长度为 1 的子序列
  • 复杂度：时间 O(n²)，空间 O(n)
