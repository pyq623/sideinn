第 95 题 编辑距离

LeetCode 72 Edit Distance

难度 中等 标签 多维动态规划 字符串 动态规划 原题链接

题面

给你两个单词 word1 和 word2， 请返回将 word1 转换成 word2 所使用的最少操作数。

你可以对一个单词进行如下三种操作：

  • 插入一个字符
  • 删除一个字符
  • 替换一个字符

示例 1：

输入： word1 = "horse", word2 = "ros"
输出： 3
解释：
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')

示例 2：

输入： word1 = "intention", word2 = "execution"
输出： 5
解释：
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')

提示：

  • 0 <= word1.length, word2.length <= 500
  • word1 和 word2 由小写英文字母组成

思路

和上一题（最长公共子序列）结构非常像，几乎同一个骨架。

dp[i][j] = word1 前 i 个字符变成 word2 前 j 个字符的最少操作数。

递推逻辑

相等时：word1[i-1] == word2[j-1]，不需要操作

dp[i][j] = dp[i-1][j-1]

不等时：三种操作选最少的

dp[i][j] = min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]) + 1
  • dp[i-1][j-1] + 1：替换 word1[i-1] 为 word2[j-1]
  • dp[i-1][j] + 1：删除 word1[i-1]（word1 少看一个字符）
  • dp[i][j-1] + 1：插入 word2[j-1] 到 word1（word2 少看一个字符）

和 LCS 的代码对比

# 最长公共子序列
if text1[i-1] == text2[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1        # 匹配，LCS 长度 +1
else:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])  # 跳过一个

# 编辑距离
if word1[i-1] == word2[j-1]:
    dp[i][j] = dp[i-1][j-1]            # 相等，不操作
else:
    dp[i][j] = min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]) + 1  # 三选一

最长公共子序列

编辑距离

相等时

dp[i-1][j-1] + 1（找到公共字符）

dp[i-1][j-1]（不需要操作）

不等时

max(上, 左) 2 个方向

min(左上, 上, 左) + 1 3 个方向

边界

全 0（空串 LCS=0）

dp[i][0]=i, dp[0][j]=j（删/插）

边界条件

  • dp[i][0] = i：word1 前 i 个字符变成空串，需要删除 i 次
  • dp[0][j] = j：空串变成 word2 前 j 个字符，需要插入 j 次

举例

word1 = "horse", word2 = "ros"

    ""  r  o  s
""   0  1  2  3
h    1  1  2  3
o    2  2  1  2
r    3  2  2  2
s    4  3  3  2
e    5  4  4  3  ← 答案 3

代码实现

class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m = len(word1)
        n = len(word2)
        dp = [[0] * (n + 1) for _ in range(m+1)]

        for i in range(m+1):
            dp[i][0] = i
        for j in range(n+1):
            dp[0][j] = j
        for i in range(1, m+1):
            for j in range(1, n+1):
                if word1[i-1] == word2[j-1]:
                    dp[i][j] = dp[i-1][j-1]
                else:
                    dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
        return dp[m][n]
  • 易错点：
  1. 边界是 `dp[i][0]=i` 和 `dp[0][j]=j`，不是全 0：变成空串需要删 i 次，空串变成目标需要插 j 次。和 LCS 不同
  2. 相等时不加 1：字符相等不需要操作，直接继承 dp[i-1][j-1]。容易和 LCS 搞混（LCS 相等时要 +1）
  3. 不等时是 3 个方向取 min：替换（左上）、删除（上）、插入（左），都要 +1。LCS 不等时只看 2 个方向且不 +1
  4. `word1[i-1]` 不是 `word1[i]`：和 LCS 一样，dp 的 i 代表"前 i 个字符"（长度），对应下标要 -1
  • 复杂度：时间 O(m × n)，空间 O(m × n)
