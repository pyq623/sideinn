第 54 题 实现 Trie (前缀树)

LeetCode 208 Implement Trie (Prefix Tree)

难度 中等 标签 图论 设计 字典树 哈希表 字符串 原题链接

题面

Trie （发音类似 "try"）或者说 前缀树 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。

请你实现 Trie 类：

  • Trie() 初始化前缀树对象。
  • void insert(String word) 向前缀树中插入字符串 word 。
  • boolean search(String word) 如果字符串 word 在前缀树中，返回 true（即，在检索之前已经插入）；否则，返回 false 。
  • boolean startsWith(String prefix) 如果之前已经插入的字符串 word 的前缀之一为 prefix ，返回 true ；否则，返回 false 。

示例：

输入
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
输出
[null, null, true, false, true, null, true]

解释
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 True
trie.search("app");     // 返回 False
trie.startsWith("app"); // 返回 True
trie.insert("app");
trie.search("app");     // 返回 True

提示：

  • 1 <= word.length, prefix.length <= 2000
  • word 和 prefix 仅由小写英文字母组成
  • insert、search 和 startsWith 调用次数 总计 不超过 3 * 10^4 次

思路

Trie 前缀树 是什么

一种树，每条边代表一个字母，从根到某个节点的路径就是一个前缀。公共前缀共享路径，不同部分各走各的分支。

数据结构

每个节点就是一个 Trie 对象，有两样东西：

  • `children`：dict，记录"下一个字母 → 子节点（又一个 Trie 对象）"
  • `is_end`：布尔值，标记"是否有单词在这里结束"
def __init__(self):
    self.children = {}      # {'a': Trie(), 'p': Trie(), ...}
    self.is_end = False

dict 里的 value 是另一个 Trie，每个 Trie 又有自己的 dict……一层套一层，自然形成树结构。和链表的 ListNode(val, next=ListNode(...)) 是同一个思路。

图示 插入 "apps" 再插入 "apple"

insert("apps") — 逐字母铺路：

root → 'a' → 'p' → 'p' → 's'(is_end=True)

insert("apple") — 公共前缀 "app" 已存在，直接走过去，在 'p' 处分叉：

ch = 'a'  → 已存在，走过去
ch = 'p'  → 已存在，走过去
ch = 'p'  → 已存在，走过去
ch = 'l'  → 不存在！创建新节点（分叉）
ch = 'e'  → 不存在，创建新节点
标记 is_end = True

最终结构：

root → 'a' → 'p' → 'p' → 's'(is_end=True)
                     |
                     └→ 'l' → 'e'(is_end=True)

节点 'p' 的 children = {'s': Trie(), 'l': Trie()}，一个节点可以有多个子节点。

内存中的实际嵌套结构 插入 "app" 后

self = {
    children: {
        'a': {                          # Trie 对象
            children: {
                'p': {                  # Trie 对象
                    children: {
                        'p': {          # Trie 对象
                            children: {},
                            is_end: True   ← "app" 在这里结束
                        }
                    },
                    is_end: False
                }
            },
            is_end: False
        }
    },
    is_end: False
}

三个方法的逻辑

三个方法的遍历部分完全一样（逐字母往下走），唯一区别在"不存在时怎么办"和"最后返回什么"：

方法

字母不存在时

走完后返回

insert

创建新节点

标记 is_end = True

search

return False

node.is_end（必须是完整单词）

startsWith

return False

True（能走完就行）

代码实现

class Trie:

    def __init__(self):
        self.childern = {}
        self.is_end = False

    def insert(self, word: str) -> None:
        node = self
        for ch in word:
            if ch not in node.childern:
                node.childern[ch] = Trie()
            node = node.childern[ch]
        node.is_end = True

    def search(self, word: str) -> bool:
        node = self
        for ch in word:
            if ch not in node.childern:
                return False
            node = node.childern[ch]
        return node.is_end

    def startsWith(self, prefix: str) -> bool:
        node = self
        for ch in prefix:
            if ch not in node.childern:
                return False
            node = node.childern[ch]
        return True
  • 易错点：
  1. `search` 和 `startsWith` 的区别只在最后一行：search 返回 node.is_end（"app" 是前缀但不是完整单词时返回 False），startsWith 返回 True（能走完就行）
  2. `node = self` 开头别忘：self 就是根节点，所有单词都从根出发。就像查字典一定从第一页开始，不可能从中间某页开始查。每次 insert/search/startsWith 都必须从根开始一个字母一个字母往下走
  3. `node.children[ch] = Trie()` 创建的是新的 Trie 对象：不是字符串，不是布尔值，是一个完整的节点（有自己的 children 和 is_end）
  4. `node = node.children[ch]` 要在 if 外面：不管是新建的还是已存在的，都要移动到下一个节点
  • 复杂度：insert/search/startsWith 时间都是 O(n)（n 为单词长度），空间 O(T)（T 为所有插入字符的总数）
