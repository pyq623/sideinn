第 59 题 括号生成

LeetCode 22 Generate Parentheses

难度 中等 标签 回溯 字符串 动态规划 原题链接

题面

数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 有效的 括号组合。

示例 1：

输入： n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]

示例 2：

输入： n = 1
输出：["()"]

提示：

  • 1 <= n <= 8

思路

  • 还是回溯，和电话号码（第 57 题）很像：每个位置做选择，path 是字符串天然回溯
  • 区别：候选只有 ( 和 ) 两个，但有条件限制

两个约束

  1. `open < n`：才能放 (（左括号最多 n 个）
  2. `close < open`：才能放 )（右括号不能超过已有的左括号，否则不合法）

决策树 n 2

                    ""
              /           \
           "("             ")" ✗（close > open，不合法）
          /    \
       "(("    "()"
        |      /    \
      "(()"  "()("   "())" ✗（close > open）
        |      |
     "(())" "()()"

和组合总和 第 58 题 的对比 "剪枝在前"还是"终止在前"

这题看起来和以往不同：之前都是 for 循环 + 终止条件在开头，这题变成了 if 条件判断后才递归。其实本质完全一样：

# 组合总和：for 循环 + 终止条件在开头
def dfs(start, path, cur_sum):
    if cur_sum == target:        # 终止：成功
        self.res.append(path[:])
        return
    if cur_sum > target:         # 终止：失败（剪枝）
        return
    for i in range(start, n):    # 候选有很多个
        path.append(candidates[i])
        dfs(i, path, cur_sum + candidates[i])
        path.pop()

# 括号生成：if 条件 + 没有 for 循环
def dfs(path, opens, closes):
    if len(path) == 2 * n:       # 终止：成功
        self.res.append(path)
        return
    if opens < n:                # 候选1：放 (
        dfs(path + '(', opens + 1, closes)
    if closes < opens:           # 候选2：放 )
        dfs(path + ')', opens, closes + 1)

把括号生成硬写成 for 循环版本，就能看出完全一样的模板：

def dfs(path, opens, closes):
    if len(path) == 2 * n:
        self.res.append(path)
        return
    for c in ['(', ')']:              # 候选：( 或 )
        if c == '(' and opens >= n:       # 剪枝：左括号用完了
            continue
        if c == ')' and closes >= opens:  # 剪枝：右括号不能超过左括号
            continue
        dfs(path + c,
            opens + (1 if c == '(' else 0),
            closes + (1 if c == ')' else 0))

组合总和（第 58 题）

括号生成（本题）

候选个数

很多（candidates 数组）

只有 2 个：( 和 )

遍历方式

for i in range(start, n)

两个 if（等价于 for + continue）

剪枝

cur_sum > target → return

opens >= n / closes >= opens → 不进入

本质

先检查能不能选，能才递归

完全一样

候选只有两个，for 循环退化成了两个 if，所以看起来不同，本质一模一样。

字符串天然回溯

和第 57 题一样，path + '(' 创建新字符串传下去，上层的 path 根本没变，不需要手动回溯。

代码实现

class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        self.res = []
        def dfs(path, opens, closes):
            if len(path) == 2 * n:
                self.res.append(path[:])
                return
            if opens < n:
                dfs(path + '(', opens + 1, closes)
            if closes < opens:
                dfs(path + ')', opens, closes + 1)
        path = ""
        dfs(path, 0, 0)
        return self.res
  • 易错点：
  1. `closes < opens` 不是 `closes < n`：右括号的上限是当前已有的左括号数，不是 n。写成 < n 会生成非法括号如 )(
  2. 两个 if 不是 if-else：一个位置可能既能放 ( 又能放 )，两个条件是独立的分支，不是互斥的
  3. 不需要手动回溯：path 是字符串（不可变类型），path + '(' 创建新对象，上层不受影响
  • 复杂度：时间 O(\frac4^n\sqrtn)（第 n 个卡特兰数），空间 O(n)（递归深度）
