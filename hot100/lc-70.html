第 81 题 爬楼梯

LeetCode 70 Climbing Stairs

难度 简单 标签 动态规划 记忆化 数学 原题链接

题面

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

示例 1：

输入： n = 2
输出： 2
解释： 有两种方法可以爬到楼顶。
1. 1 阶 + 1 阶
2. 2 阶

示例 2：

输入： n = 3
输出： 3
解释： 有三种方法可以爬到楼顶。
1. 1 阶 + 1 阶 + 1 阶
2. 1 阶 + 2 阶
3. 2 阶 + 1 阶

提示：

  • 1 <= n <= 45

思路

到第 i 阶只有两种来法：

  • 从第 i-1 阶跳 1 步上来
  • 从第 i-2 阶跳 2 步上来

所以：dp[i] = dp[i-1] + dp[i-2]（两拨方案互不重叠，加起来就是总方案数）

dp[0] = 1, dp[1] = 1

dp[2] = dp[1] + dp[0] = 1 + 1 = 2  （跳1+1 或 直接跳2）
dp[3] = dp[2] + dp[1] = 2 + 1 = 3  （1+1+1, 1+2, 2+1）
dp[4] = dp[3] + dp[2] = 3 + 2 = 5

本质就是斐波那契数列。

为什么 dp 0 1

因为 dp[2] = dp[1] + dp[0]，而到第 2 阶明确有 2 种方法（1+1 和直接跳 2）。dp[1] = 1，所以 dp[0] 必须等于 1 才能让 dp[2] = 2 算对。dp[0] = 1 的含义是"直接从地面跳 2 步到第 2 阶"这条路径存在。如果 dp[0] = 0，就丢掉了"直接跳 2 步"这种方法。

为什么是加法不是 max

这题求的是方案数（有多少种走法），不是最大值。两种来法（从 i-1 跳 1 步、从 i-2 跳 2 步）的方案互不重叠，所以加起来就是总数。

代码实现

class Solution:
    def climbStairs(self, n: int) -> int:
        dp = [0] * (n + 1)
        dp[0] = 1
        dp[1] = 1
        for i in range(2, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]
        return dp[n]
  • 易错点：
  1. 用加法不是 max：求方案数是累加，不是取最大值。max(dp[i-1]+1, dp[i-2]+2) 完全错误
  2. `dp[0] = 1` 不是 0：地面是起点，算 1 种方式。设为 0 会导致 dp[2] 少算"直接跳 2 步"的路径
  3. 循环从 2 开始到 n（含）：range(2, n+1)，别漏了 n
  • 复杂度：时间 O(n)，空间 O(n)（可优化到 O(1)，只保留前两个值）
