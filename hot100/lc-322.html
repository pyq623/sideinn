第 85 题 零钱兑换

LeetCode 322 Coin Change

难度 中等 标签 动态规划 广度优先搜索 数组 原题链接

题面

给你一个整数数组 coins ，表示不同面额的硬币；以及一个整数 amount ，表示总金额。

计算并返回可以凑成总金额所需的 最少的硬币个数 。如果没有任何一种硬币组合能组成总金额，返回 -1 。

你可以认为每种硬币的数量是无限的。

示例 1：

输入： coins = [1, 2, 5], amount = 11
输出：3
解释： 11 = 5 + 5 + 1

示例 2：

输入： coins = [2], amount = 3
输出： -1

示例 3：

输入： coins = [1], amount = 0
输出： 0

提示：

  • 1 <= coins.length <= 12
  • 1 <= coins[i] <= 231 - 1
  • 0 <= amount <= 104

思路

和上一题（完全平方数）几乎一模一样！

完全平方数

零钱兑换

"硬币"是什么

1, 4, 9, 16, ...（完全平方数）

coins 数组里的面额

求什么

最少用几个平方数凑出 n

最少用几个硬币凑出 amount

无解情况

一定有解（1 是完全平方数）

可能无解，返回 -1

递推：dp[i] = min(dp[i - coin] + 1)，对所有 coin <= i 的硬币。

coins = [1, 2, 5], amount = 11

dp[0] = 0
dp[1] = dp[0]+1 = 1        （1）
dp[2] = min(dp[1]+1, dp[0]+1) = 1  （直接用 2）
dp[3] = min(dp[2]+1, dp[1]+1) = 2  （2+1）
dp[5] = min(dp[4]+1, dp[3]+1, dp[0]+1) = 1  （直接用 5）
...
dp[11] = 3                  （5+5+1）

代码实现

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        dp = [inf] * (amount + 1)
        dp[0] = 0
        for i in range(1, amount + 1):
            for j in range(len(coins)):
                if i >= coins[j]:
                    dp[i] = min(dp[i], dp[i - coins[j]] + 1)
        if dp[amount] == inf:
            return -1
        else:
            return dp[amount]
  • 易错点：
  1. 必须遍历所有硬币，不能用 while + `i >= coins[j]` 提前退出：coins 不一定有序，遇到一个大面额就停掉会跳过后面的小面额。比如 coins=[474,83,404,3]，i=264 时第一个就大于 i，但 coins[3]=3 是可用的
  2. 无解返回 -1：和完全平方数不同，这题可能凑不出 amount（比如 coins=[2], amount=3），dp[amount] 还是 inf 就说明无解
  3. `dp[0] = 0`：凑出 0 元需要 0 个硬币，和完全平方数一样
  • 复杂度：时间 O(amount × len(coins))，空间 O(amount)
