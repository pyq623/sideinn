第 74 题 数组中的第K个最大元素

LeetCode 215 Kth Largest Element in an Array

难度 中等 标签 堆 数组 分治 快速选择 排序 堆（优先队列） 原题链接

题面

给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。

请注意，你需要找的是数组排序后的第 k 个最大的元素，而不是第 k 个不同的元素。

你必须设计并实现时间复杂度为 O(n) 的算法解决此问题

示例 1:

输入: [3,2,1,5,6,4], k = 2
输出: 5

示例 2:

输入: [3,2,3,1,2,4,5,5,6], k = 4
输出: 4

提示：

  • 1 <= k <= nums.length <= 105
  • -104 <= nums[i] <= 104

思路

解法一 小顶堆 O n log k 能通过但不是最优

维护一个大小为 k 的小顶堆，遍历数组，堆超过 k 就弹出最小的。最后堆顶就是第 k 大。

import heapq
heap = []
for num in nums:
    heapq.heappush(heap, num)
    if len(heap) > k:
        heapq.heappop(heap)
return heap[0]

Python 的 heapq 是小顶堆（最小的在堆顶），要大顶堆就取负号存入。

解法二 快速选择 O n

核心思路：第 k 大 = 从大到小排第 k 个。随机选一个 pivot，把数组分成三组：比 pivot 大的、等于 pivot 的、比 pivot 小的。然后看第 k 大落在哪一组，只对那一组递归。

nums = [3,2,1,5,6,4], k = 2, pivot = 3

big   = [5, 6, 4]    （> 3）
equal = [3]           （== 3）
small = [2, 1]        （< 3）

k=2 <= len(big)=3 → 第2大在 big 里，递归 quick_select(big, 2)

为什么不用双指针分区

最初的写法用双指针原地分区（只分成 ≤ pivot 和 ≥ pivot 两部分），遇到大量重复元素时（如测试用例全是 1），pivot 分区极不均匀，退化到 O(n²) 超时。

分成三组（big / equal / small）天然解决了这个问题：所有等于 pivot 的元素归入 equal，如果 target 落在 equal 里直接返回 pivot，不会反复递归。

双指针分区写法 能通过 44 46 用例 大量重复元素超时

class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        import random
        n = len(nums)
        target = n - k
        def quickselect(left, right):
            p_idx = random.randint(left, right)
            nums[left], nums[p_idx] = nums[p_idx], nums[left]
            i, j = left + 1, right
            while i <= j:
                while i <= j and nums[i] <= nums[left]:
                    i += 1
                while i <= j and nums[j] >= nums[left]:
                    j -= 1
                if i < j:
                    nums[i], nums[j] = nums[j], nums[i]
            nums[left], nums[j] = nums[j], nums[left]
            if j < target:
                return quickselect(j + 1, right)
            elif j > target:
                return quickselect(left, j - 1)
            else:
                return nums[j]
        return quickselect(0, n - 1)

超时原因：只分成两组（≤ pivot 和 ≥ pivot），当大量元素等于 pivot 时，pivot 几乎总落在一端，每轮只减少一个元素，退化到 O(n²)。

分区过程：

  1. 随机选 pivot，放到最左边
  2. i 从左往右找比 pivot 大的，j 从右往左找比 pivot 小的，交换
  3. 循环结束时 i > j，把 pivot 和 nums[j] 交换归位（和 j 换不是 i，因为 nums[j] ≤ pivot 是安全的，nums[i] ≥ pivot 会破坏分区）
  4. 比较 j 和 target = n - k 的大小，只往一边递归

判断第 k 大在哪一组

big:   [> pivot]     len(big) 个
equal: [== pivot]    len(equal) 个
small: [< pivot]     len(small) 个

从大到小排列是 big + equal + small，所以：

  • k <= len(big) → 第 k 大在 big 里，递归 quick_select(big, k)
  • k <= len(big) + len(equal) → 第 k 大在 equal 里，直接返回 pivot
  • 否则 → 第 k 大在 small 里，递归 quick_select(small, k - len(big) - len(equal))

代码中 len(nums) - len(small) < k 等价于 k > len(big) + len(equal)。

代码实现

class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        import random
        target = k
        def quickselect(nums, target):
            small, equal, big = [], [], []
            pivot = random.choice(nums)
            for num in nums:
                if num < pivot:
                    small.append(num)
                elif num > pivot:
                    big.append(num)
                else:
                    equal.append(num)
            if target <= len(big):
                return quickselect(big, target)
            elif len(nums) - len(small) < target:
                return quickselect(small, target - (len(nums) - len(small)))
            else:
                return equal[0]
        result = quickselect(nums, k)
        return result
  • 易错点：
  1. 必须分三组，不能只分两组：只分成 ≤ pivot 和 > pivot 两组，大量重复元素时分区不均匀，退化到 O(n²) 超时
  2. 递归里全部用参数 `target`，不能用外层的 `k`：递归时 target 会调整，k 永远是最初的值，混用会导致判断错误、递归到空列表报错
  3. `random.choice(nums)` 不是 `random.randint(nums)`：choice 从列表随机选一个元素，randint(a, b) 需要两个整数参数
  4. 递归 small 时 target 要调整：big 和 equal 的元素都比 small 大，已经排在前面了，所以 target 要减掉它们的数量：target - (len(nums) - len(small))
  5. `heapq` 是小顶堆：Python 没有内置大顶堆，要大顶就取负号。找第 k 大用小顶堆就够
  • 复杂度：快速选择平均 O(n)，空间 O(n)（三个列表）

为什么是 O(n)？ 因为每轮只往一边递归，处理的数据量每轮大约砍半：

  第 1 轮：扫描 n 个元素做分区
  第 2 轮：扫描 n/2 个元素（只看一半）
  第 3 轮：扫描 n/4 个元素
  ...

  总共：n + n/2 + n/4 + n/8 + ... = 2n = O(n)

对比快排（O(n log n)）：快排每轮要处理两边，总共 n × log n 层。快速选择只处理一边，所以更快。
