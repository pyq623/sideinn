第 11 题 滑动窗口最大值

LeetCode 239 Sliding Window Maximum

难度 困难 标签 子串 队列 数组 滑动窗口 单调队列 堆（优先队列） 原题链接

题面

给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。

返回 滑动窗口中的最大值 。

示例 1：

输入： nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7      5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7

示例 2：

输入： nums = [1], k = 1
输出：[1]

提示：

  • 1 <= nums.length <= 105
  • -104 <= nums[i] <= 104
  • 1 <= k <= nums.length

思路

  • 暴力法：每次窗口滑动后遍历窗口内所有元素取最大值，复杂度 O((n-k+1) × k) ≈ O(nk)
  • 单调队列优化：
  • 维护一个单调递减的双端队列 deque，队首始终是当前窗口的最大值
  • 核心操作（每次右指针 j 前进一步）：
  1. 删除过期元素：如果队首元素恰好是即将离开窗口的 nums[i-1]，弹出队首
  2. 维护单调性：从队尾弹出所有比 nums[j] 小的元素（它们不可能再成为最大值了）
  3. 加入新元素：将 nums[j] 加入队尾
  4. 记录结果：窗口满了（i >= 0）时，队首就是最大值
  • 为什么队首等于 nums[i-1] 就能判断是要删除的那个元素？
  • 如果离开的元素不是最大值，它早就在更大元素入队时被弹出了，不在 deque 里
  • 如果离开的元素是最大值，它一定在队首
  • 如果有重复的最大值，deque 保留了所有相等的值（非严格递减），popleft 只弹一个，剩下的对应窗口内还存在的元素
  • i 的含义：窗口左边界，从 1-k 开始。i < 0 表示窗口未满，i >= 0 表示窗口已满开始输出结果
  • 易错点：
  1. `i` 的范围：range(1 - k, n + 1 - k)，终点是 n + 1 - k 不是 n - k - 1，差 2 会导致漏掉最后的窗口
  2. while 条件：while deque and ...，不是 while not deque and ...（后者在 deque 为空时进入循环，访问 deque[-1] 会报错）
  3. 删除对比的是 `nums[i-1]`：是刚离开窗口的元素，不是 nums[i]（nums[i] 还在窗口内）
  4. 删除条件是 `i > 0`：不是 i >= 0。i = 0 时没有元素离开（窗口刚满），i > 0 才开始有元素离开

代码实现

import collections
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        res = []
        if not nums and k == 0:
            return res

        n = len(nums)
        deque = collections.deque()
        for i, j in zip(range(1-k, n+1-k), range(n)):
            if i > 0 and deque[0] == nums[i-1]:
                deque.popleft()

            while deque and nums[j] > deque[-1]:
                deque.pop()  # 从末尾开始，头部永远是最大，先进入的在右边。

            deque.append(nums[j])

            if i >= 0:
                res.append(deque[0])
        return res
  • 复杂度：时间 O(N)（每个元素最多进出队列各一次），空间 O(k)（队列最多存 k 个元素）

deque 的语法知识

deque：双端队列

两端添加、删除都是 O(1)，适合 BFS、层序遍历、滑动窗口最大值。

from collections import deque
q = deque([1, 2])
q.append(3)        # 右端加入
x = q.popleft()   # 左端取出：1
q.appendleft(0)   # 左端加入
x = q.pop()       # 右端取出：3
