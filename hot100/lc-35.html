第 63 题 搜索插入位置

LeetCode 35 Search Insert Position

难度 简单 标签 二分查找 数组 原题链接

题面

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 O(log n) 的算法。

示例 1:

输入: nums = [1,3,5,6], target = 5
输出: 2

示例 2:

输入: nums = [1,3,5,6], target = 2
输出: 1

示例 3:

输入: nums = [1,3,5,6], target = 7
输出: 4

提示:

  • 1 <= nums.length <= 104
  • -104 <= nums[i] <= 104
  • nums 为 无重复元素 的 升序 排列数组
  • -104 <= target <= 104

思路

  • 数组有序，每次看中间的数，比 target 小就去右半边，比 target 大就去左半边，相等就找到了
  • 没找到时，left 刚好就是插入位置

二分查找的核心

nums = [1, 3, 5, 6], target = 5

第一轮：left=0, right=3, mid=1 → nums[1]=3 < 5 → left=2
第二轮：left=2, right=3, mid=2 → nums[2]=5 == 5 → 返回 2 ✓

没找到时 left 就是插入位置：

nums = [1, 3, 5, 6], target = 2

第一轮：left=0, right=3, mid=1 → nums[1]=3 > 2 → right=0
第二轮：left=0, right=0, mid=0 → nums[0]=1 < 2 → left=1
第三轮：left=1, right=0 → left > right，循环结束

left=1，就是 2 应该插入的位置 → [1, 2, 3, 5, 6] ✓

二分查找 与 双指针 小于等于 还是 小于

之前第 2 章的双指针题用的是 while left < right，二分查找用的是 while left <= right，容易搞混。它们是完全不同的两种算法：

# 双指针（第 7 题 盛最多水）：两端往中间走，相遇就停
left, right = 0, len(height) - 1
max_area = 0
while left < right:                    # 相遇就停
    area = min(height[left], height[right]) * (right - left)
    max_area = max(max_area, area)
    if height[left] < height[right]:
        left += 1                      # 矮的那边往里走
    else:
        right -= 1
return max_area

# 二分查找（本题）：不断砍半，搜索区间为空才停
left, right = 0, len(nums) - 1
while left <= right:                   # left == right 时还剩一个元素要检查
    mid = (left + right) // 2
    if nums[mid] < target:
        left = mid + 1
    elif nums[mid] > target:
        right = mid - 1
    else:
        return mid
return left

双指针

二分查找

每轮做什么

挪一步（left++ 或 right--）

砍一半（搜索范围减半）

前提条件

不一定要有序

必须有序（或有单调性）

两个指针的含义

两个选择（左边界和右边界）

一个搜索范围的左端和右端

有没有 mid

没有

有，每轮算 mid 看中间值

循环条件

left < right

left <= right

一句话区分：看到 mid = (left + right) // 2 就是二分，没有 mid 就是双指针。

为什么二分要 小于等于

因为 left == right 的时候还剩一个元素没检查：

nums = [1, 3, 5], target = 5

left=0, right=2, mid=1 → nums[1]=3 < 5 → left=2
left=2, right=2 → 还剩 nums[2]=5 没看！

如果用 left < right，这里就退出了，漏掉了答案
如果用 left <= right，再查一次 mid=2 → 找到了 ✓

代码实现

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] < target:
                left = mid + 1
            elif nums[mid] > target:
                right = mid - 1
            else:
                return mid
        return left
  • 易错点：
  1. `while left <= right` 不是 `left < right`：left == right 时还剩一个元素要检查，用 < 会漏掉
  2. `left = mid + 1` / `right = mid - 1`：不能写 left = mid / right = mid，否则 left == right 时死循环
  3. 返回 `left` 不是 `mid`：循环结束时 left 就是第一个大于等于 target 的位置，即插入位置
  4. `mid = (left + right) // 2`：整除取中间，Python 不会溢出所以不需要写 left + (right - left) // 2
  • 复杂度：时间 O(log n)（每轮砍半），空间 O(1)
