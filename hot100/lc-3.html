第 08 题 无重复字符的最长子串

LeetCode 3 Longest Substring Without Repeating Characters

难度 中等 标签 滑动窗口 哈希表 字符串 原题链接

题面

给定一个字符串 s ，请你找出其中不含有重复字符的 最长 子串 的长度。

示例 1:

输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

示例 2:

输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。

示例 3:

输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个 子序列， 不是子串。

提示：

0 <= s.length <= 5 104

  • s 由英文字母、数字、符号和空格组成

分析

  • 暴力法复杂度为 O(N³)：共有 N(1+N)/2 个子串（等差数列求和），判断每个子串是否有重复字符需要 O(N)

解法一 滑动窗口 加 哈希表

  • 思路
  • 因为求的是连续子串，所以用双指针维护一个窗口 (i, j]（i 是开区间左端点，j 是闭区间右端点）
  • 右指针 j 不断右移扩展窗口；当发现 s[j] 在窗口内已经出现过，左指针 i 直接跳到上一次出现的位置，跳过重复
  • 两个巧妙的设计：
  • hash_dic[s[j]] = j：哈希表记录每个字符最后一次出现的下标，这样遇到重复时可以 O(1) 跳转，不用逐步收缩左边界
  • i = max(i, hash_dic[s[j]])：取 max 是因为 i 只能往右走。哈希表里记录的旧位置可能已经在 i 左边（已经被排除在窗口外了），不能回退
  • i 初始值为 -1：因为 i 是开区间端点，窗口长度 = j - i。初始时窗口左侧没有任何字符，放在下标 0 之前即 -1
  • 代码实现
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        i = -1
        res = 0
        hash_dic = {}
        for j in range(len(s)):
            if s[j] in hash_dic: # 重复出现了
                i = max(i, hash_dic[s[j]])
            res = max(res, (j - i)) # 每次都比较，因为可能出现从头到尾都没有重复的情况
            hash_dic[s[j]] = j
        return res
  • 复杂度：时间 O(N)，空间 O(N)（哈希表最多存储字符集大小个键）

解法二 动态规划

  • 思路
  • 定义 dp[j] = 以 s[j] 为结尾的最长无重复子串长度，用 last_j 记录 dp[j-1]
  • i = s[j] 上一次出现的位置（没出现过则为 -1）
  • 判断条件本身就是更新值的来源，分类讨论（画一维线段图理解）：
  • 若 last_j + 1 <= j - i：说明 i 比以 j-1 为末尾的子串起点更靠左，即上次重复在当前窗口之外。以 j-1 结尾时已经因为其他重复而缩小过了，所以 dp[j] = last_j + 1（在前一个长度基础上 +1 即可）
  • 否则：i 落在当前窗口内部，必须从 i 处截断，dp[j] = j - i
  • 最终答案 = 所有 dp[j] 的最大值
  • 代码实现
    class Solution:
        def lengthOfLongestSubstring(self, s: str) -> int:
            i = -1
            j = 0
            hash_dict = dict()
            res = 0
            last_j = 0
            for j in range(len(s)):
                i = hash_dict.get(s[j], -1) # 如果没找到就是-1
                if last_j + 1 <= j - i:
                    res = max(res, last_j + 1)
                    last_j = last_j + 1
                else:
                    res = max(res, j - i)
                    last_j = j - i
                hash_dict[s[j]] = j
            return res
  • 复杂度：时间 O(N)，空间 O(N)
