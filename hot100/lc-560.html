第 10 题 和为 K 的子数组

LeetCode 560 Subarray Sum Equals K

难度 中等 标签 子串 数组 哈希表 前缀和 原题链接

题面

给你一个整数数组 nums 和一个整数 k ，请你统计并返回 该数组中和为 k 的子数组的个数 。

子数组是数组中元素的连续非空序列。

示例 1：

输入： nums = [1,1,1], k = 2
输出： 2

示例 2：

输入： nums = [1,2,3], k = 3
输出： 2

提示：

1 <= nums.length <= 2 104

  • -1000 <= nums[i] <= 1000
  • -107 <= k <= 107

思路

  • 错误尝试：滑动窗口
    class Solution:
        def subarraySum(self, nums: List[int], k: int) -> int:
            l = 0
            sum = 0
            res = 0
            for r in range(len(nums)):
                sum = sum + nums[r]
                while sum > k and l < r:
                    sum = sum - nums[l]
                    l = l + 1
                if sum == k:
                    res += 1
            return res
  • 错误原因：滑动窗口的前提是单调性——右指针右移窗口和增大，左指针右移窗口和减小。但本题 nums[i] 可以是负数，单调性被破坏：
  • 右指针加入一个负数，和可能变小
  • 左指针移除一个负数，和可能变大
  • 所以 while sum > k 收缩左边界不一定能让和减小，逻辑不成立
  • 经验：滑动窗口适用于数组元素全为正数（或全为非负数）的场景。数组含负数时，无法保证窗口的单调性，需要换用前缀和 + 哈希表的思路
  • 正确思路：前缀和 + 哈希表
  • 子数组 nums[i..j] 的和 = s[j+1] - s[i]，其中 s 是前缀和数组
  • 要找和为 k 的子数组，即找满足 s[j] - s[i] = k 的 (i, j) 对，变形为 s[i] = s[j] - k
  • 遍历每个 s[j]，用哈希表记录之前出现过的前缀和次数，查找 s[j] - k 出现了几次就有几个合法子数组
  • 不需要去重：每个相同的前缀和值代表一个不同的起点位置，每个起点都构成一个独立的合法子数组
  • 知识点：s = [0] * (len(nums) + 1)
  • 前缀和数组比原数组长 1，s[0] = 0 表示"前 0 个元素的和"
  • 这样 s[i+1] - s[j] 就能表示任意子数组 nums[j..i] 的和，包括从下标 0 开始的子数组（s[i+1] - s[0]）
  • 如果不设 s[0] = 0，就无法处理"从头开始的子数组和恰好等于 k"的情况

解法一 两次遍历

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        res = 0
        s = [0] * (len(nums) + 1)

        for i in range(len(nums)):
            s[i+1] = s[i] + nums[i]

        cnt = defaultdict(int)
        for s_j in s:
            res = res + cnt[s_j - k]
            cnt[s_j] += 1
        return res

解法二 单次遍历

  • 思想：可以一边计算前缀和，一边查找哈希表，不需要先把前缀和数组算完再遍历
  • 对比两次遍历的代码循环了 n+1 次（遍历 s[0] 到 s[n]），单次遍历循环了 n 次。少的那一次就是对 s[0] = 0 的统计——所以在遍历之前，手动 cnt[0] = 1，相当于提前把 s[0] 的那一轮处理掉了
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        cnt = defaultdict(int)
        cnt[0] = 1  # 提前统计 s[0]=0，即空前缀的元素和等于 0
        res = 0
        sum_x = 0
        for x in nums:
            sum_x += x
            res += cnt[sum_x - k]
            cnt[sum_x] += 1
        return res
  • 复杂度：时间 O(N)，空间 O(N)
