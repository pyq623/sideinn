从复刻到改进

复刻版保留官方图的双栏布局、GDN Layer ×3 / QSA Layer ×1、GR Read / GR Write 和底部输入路线，是可编辑的矢量重绘。改进版将第一组单独展开、其余十一组用 ×11 表示，给出全部 48 层编号，并突出 N-gram Embedding Layer 仅在第 2 层接入。×N 表示结构重复，各层参数独立。

GDN Layer / QSA Layer
GDN Layer 内使用 Gated DeltaNet，QSA Layer 内使用 Qwen Sparse Attn；两类层均包含 MoE 及各自的 GR Read / GR Write。Qwen Sparse Attn 是官方图采用的标签，对应正文全称 Qwen Sparse Attention（QSA）；两版图统一沿用 Qwen Sparse Attn。
Expanded Residual / Hidden States
Expanded Residual 用四个圆表示四条分支，Hidden States 用一个圆表示当前模块处理的特征；圆圈不是相加符号，也不表示额外层数。
GR Read / GR Write
GR Read 对各分支做 RMSNorm，执行按元素的门控并汇合。GR Write 根据输入分支得到每条分支的门控系数，把模块输出加回原有 Expanded Residual。GR Read 已包含归一化，因此图中不再额外添加 pre-normalization。
N-gram Embedding Layer
由 Input Tokens 的局部组合查询额外特征，只接入第 2 个 GDN Layer。层编号从 1 开始，固定配置的 ple_layer_ids 为 [2]；不在每个四层组中重复。
Vocabulary Embedding / Prediction Head / MTP Modules
Vocabulary Embedding 生成初始特征，Prediction Head 给出主输出；MTP Modules 是主干外的辅助模块，不计入 48 层。图沿用官方主干示意，不展开 Vision Encoder 和 MTP Modules 内部。

版本边界：官方称 Qwen3.8-Flash-Next 为 Qwen4 架构的早期预览。参数口径为 125B 主模型、每 token 激活 6B，另有 51B N-gram Embedding Layer 参数与 4B MTP Modules 参数；这些配置不应直接套用于 Qwen4-Max。配置快照：{{REVISION}}，核对日期：2026-11-17。
